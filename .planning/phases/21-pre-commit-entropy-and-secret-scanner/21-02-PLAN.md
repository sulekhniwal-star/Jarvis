  <name>Implement App Router Secret Scanner Endpoint & Harness Integration</name>
  <files>
    src/app/api/verification/secrets/route.ts
    src/lib/agents/engine/verification/index.ts
    src/lib/agents/engine/verification/verification-harness.ts
  </files>
  <action>
    1. Create `src/app/api/verification/secrets/route.ts`:
       - `GET /api/verification/secrets`: Returns rules, supported secret types, entropy threshold, and override instructions.
       - `POST /api/verification/secrets`:
         - Validates request body with Zod: `{ content: string, isDiff?: boolean, filePath?: string, allowedFingerprints?: string[] }`.
         - Calls `secretScanner.scanDiff` if `isDiff` is true, otherwise `secretScanner.scanText`.
         - Returns 200 with `SecretScanReport`.
         - Handles validation failure with 400.
    2. Update `src/lib/agents/engine/verification/index.ts`:
       - Export secret scanner module.
    3. Update `src/lib/agents/engine/verification/verification-harness.ts`:
       - Add `allowedSecretFingerprints?: string[]` and `enableSecretScan?: boolean` to `VerificationHarnessConfig`.
       - When `diffPatch` is provided, automatically run `secretScanner.scanDiff(activeConfig.diffPatch, { allowedFingerprints: activeConfig.allowedSecretFingerprints })`.
       - If unapproved secrets are detected (`!secretReport.passed`), set `hasFailed = true` and populate failure details.
       - Attach `secret-scan.md` to `artifacts`.
  </action>
  <verify>
    Run `pnpm.cmd exec tsc --noEmit` to verify route and harness typing.
  </verify>
  <done>
    App Router route and VerificationHarness secret scanning are operational.
  </done>
</task>
