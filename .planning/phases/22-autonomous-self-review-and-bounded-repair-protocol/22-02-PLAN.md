  <action>
    1. Create `src/lib/agents/engine/verification/repair/repair-runner.ts`:
       - Class `BoundedRepairRunner`:
         - Initializes `RepairLoopState` with `maxStrikes = 3` and captures pre-run commit SHA (`git rev-parse HEAD`).
         - `advanceStrike(errorOutput: string, stageName?: string, diffSnapshot?: string): { nextState: RepairLoopState; prompt: string; shouldRollback: boolean }`.
         - `executeRollback(preRunSha?: string, cwd?: string): Promise<boolean>`: Executes `git reset --hard <preRunSha>` and `git clean -fd` to cleanly restore the workspace to pre-run HEAD without leaving orphaned files.
         - Exposes singleton `boundedRepairRunner`.
    2. Create `src/lib/agents/engine/verification/repair/telegram-notifier.ts`:
       - Class `TelegramRecoveryNotifier`:
         - `formatRecoveryCard(taskId: string, runId: string, diagnostic: FailureDiagnostic, strikeCount: number, rollbackSha?: string): { text: string; replyMarkup: any }`.
         - Formats MarkdownV2 notification card detailing the failure category, affected files, rollback confirmation, and inline buttons (`[ 🔄 Retry Task ]`, `[ 📋 View Logs ]`, `[ ❌ Dismiss ]`).
         - `sendFailureAlert(chatId: string | number, ...)`: Dispatches via `TelegramClient`.
         - Exposes singleton `telegramRecoveryNotifier`.
    3. Update `src/lib/agents/engine/verification/repair/index.ts`:
       - Re-export runner and notifier.
  </action>
