  <name>Implement LocalSandboxRunner Fallback</name>
  <files>
    src/lib/agents/engine/sandbox/local-sandbox-runner.ts
  </files>
  <action>
    Create `src/lib/agents/engine/sandbox/local-sandbox-runner.ts`:
    1. Class `LocalSandboxRunner implements ISandboxRunner`:
       - `readonly mode = "local_process"`
       - Constructor accepts options:
         - `codingEngine`?: ICodingAgentEngine (defaults to `codingEngineRegistry.getEngine()`)
         - `workspaceRoot`?: string (defaults to `.sandbox/`)
         - `fsOps`?: `{ mkdir: (...), rm: (...), copy: (...) }` for DI testing
       - `validateEnvironment(): Promise<EngineValidationResult>`:
         - Verifies that underlying coding engine is valid and workspace root is writable.
       - `execute(context: CodingTaskContext): Promise<CodingTaskResult>`:
         - Verifies `context.targetBranch === "main"` (`NFR-SEC-01`).
         - Creates isolated temporary scratch folder for `runId` (e.g. `.sandbox/<runId>`).
         - Strips master credentials from environment variables (`NFR-SEC-02`).
         - Delegates execution to the configured coding engine.
         - Cleans up ephemeral workspace directory on completion or failure.
         - Returns `CodingTaskResult`.
  </action>
  <verify>
    Run `pnpm.cmd exec tsc --noEmit` to verify type safety.
  </verify>
  <done>
    LocalSandboxRunner provides isolated ephemeral workspace execution and automatic teardown.
  </done>
</task>

<task type="auto">
  <name>Implement SandboxOrchestrator and Publish Workflow Template</name>
  <files>
    src/lib/agents/engine/sandbox/sandbox-orchestrator.ts
    src/lib/agents/engine/sandbox/index.ts
    .github/workflows/coding-agent.yml
  </files>
  <action>
    1. Create `src/lib/agents/engine/sandbox/sandbox-orchestrator.ts`:
       - Class `SandboxOrchestrator`:
         - Holds instances of `GitHubActionsSandboxRunner` and `LocalSandboxRunner`.
         - `getActiveRunner(requestedMode?: SandboxMode): Promise<ISandboxRunner>`:
           - If mode is `"github_actions"`, validates GitHub environment.
           - If mode is `"local_process"` or `"local_docker"`, uses local runner.
           - If mode is `"auto"` or undefined: if GitHub environment is valid, uses GitHub Actions; otherwise falls back to local runner.
         - `execute(context: CodingTaskContext, mode?: SandboxMode): Promise<CodingTaskResult>`.
         - `getDiagnostics(): Promise<Record<string, unknown>>`.
    2. Create `src/lib/agents/engine/sandbox/index.ts`:
       - Re-export all types, GitHub runner, local runner, and sandbox orchestrator.
    3. Create `.github/workflows/coding-agent.yml`:
       - Declares GitHub Actions workflow with `workflow_dispatch` trigger:
         - inputs: `taskId`, `runId`, `stepId`, `allowedFiles`, `scopedInstructions`
       - Runs on `ubuntu-latest` with ephemeral container environment.
       - Steps: checkout code on `main`, setup environment, run batch execution, run verification, upload artifacts.
  </action>
  <verify>
    Run `pnpm.cmd exec tsc --noEmit` to verify exports and types.
  </verify>
  <done>
    SandboxOrchestrator, index exports, and GitHub Actions workflow template are created.
  </done>
</task>
