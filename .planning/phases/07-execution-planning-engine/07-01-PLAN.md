<task type="auto">
  <name>Implement DAG dependency analyzer and cycle detection</name>
  <files>
    src/lib/agents/planner/dag.ts
    tests/unit/agents/dag.test.ts
  </files>
  <action>
    1. Author `src/lib/agents/planner/dag.ts`:
       - `validateDAG(steps: PlanStep[], edges: DependencyEdge[]): { isValid: boolean; sortedStepIds: string[]; maxWave: number; error?: string }`
       - Implements cycle detection via topological sort (Kahn's or DFS 3-color).
       - Validates wave ordering consistency: for each step $S$ and dependency $D$, $wave(S) > wave(D)$.
       - Validates all dependency IDs exist in step array.
    2. Author `tests/unit/agents/dag.test.ts`:
       - Tests valid multi-wave DAG topological sorting.
       - Tests circular dependency detection (A -> B -> A) and error reporting.
       - Tests wave order validation (catches step in wave 1 depending on step in wave 2).
       - Tests unknown dependency reference error handling.
  </action>
</task>

    1. Author `src/lib/agents/planner/risk.ts`:

       - Inspects file paths (e.g. `supabase/migrations/`, `auth`, `package.json`), action types (`migration`, `delete`), commands (`git push`, destructive scripts).

    2. Author `src/lib/agents/planner/prompts.ts`:
       - `PLANNER_SYSTEM_PROMPT`: Directs LLM on atomic decomposition, wave sequencing, explicit file targets, verification commands, and rollback procedures.
       - `formatSpecificationForPlanner(input: PlannerInput)`: Formats specification scope, exclusions, acceptance criteria, and project context.
  </action>
</task>
