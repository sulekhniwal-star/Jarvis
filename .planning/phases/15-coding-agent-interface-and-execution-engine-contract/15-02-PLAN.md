<task type="auto">
  <name>Implement TaskContextSynthesizer</name>
  <files>
    src/lib/agents/engine/context-synthesizer.ts
  </files>
  <action>
    Create `src/lib/agents/engine/context-synthesizer.ts`:
    1. Define input parameters interface `SynthesizeContextParams`:
       - `taskId`: string (UUID)
       - `runId`: string (UUID)
       - `step`: `PlanStep`
       - `project`: `{ slug: string; repositoryUrl: string; name?: string }`
       - `taskContext`?: `{ title: string; description?: string; userPrompt?: string }`
       - `acceptanceCriteria`?: string[]
       - `targetBranch`?: string (defaults to `"main"`, throws if provided and not `"main"`)
       - `maxRetries`?: number (defaults to 3)
       - `env`?: Record<string, string>
       - `metadata`?: Record<string, unknown>
    2. Implement file pattern sanitization helper `sanitizeFilePatterns(patterns: string[]): string[]`:
       - Strips leading/trailing slashes.
       - Replaces backslashes with forward slashes for cross-platform consistency.
       - Throws `SecurityError` or filters out any pattern containing `../` or attempting parent directory traversal.
       - Deduplicates and returns normalized paths.
    3. Implement environment variable sanitizer `sanitizeEnvironmentVariables(env?: Record<string, string>): Record<string, string>`:
       - Whitelists safe variables (e.g. `NODE_ENV`, `CI`, `OPENROUTER_API_KEY` if safe) and blocks master secrets (e.g. `SUPABASE_SERVICE_ROLE_KEY`, `DATABASE_URL`, `POSTGRES_PASSWORD`, `TELEGRAM_BOT_TOKEN`, `GITHUB_WEBHOOK_SECRET`).
    4. Implement instruction compiler helper `compileScopedInstructions(params: SynthesizeContextParams): string`:
       - Generates structured markdown prompt:
         - Task Goal & Context.
         - Targeted Step: ID, Title, Description, Action Type (`create` | `modify` | etc.).
         - Explicit file modification boundaries.
         - Verification command to run and verify success.
         - Rollback procedure in case of failure.
         - Acceptance criteria bullets.
    5. Implement `synthesizeCodingTaskContext(params: SynthesizeContextParams): CodingTaskContext`:
       - Validates `targetBranch === "main"`. Throws `BranchSecurityViolationError` if branch is non-`main`.
       - Normalizes file patterns via `sanitizeFilePatterns`.
       - Sanitizes environment variables via `sanitizeEnvironmentVariables`.
       - Formats scoped instructions via `compileScopedInstructions`.
       - Validates final object against `CodingTaskContextSchema.parse()`.
       - Returns strongly typed `CodingTaskContext`.
    6. Export `TaskContextSynthesizer` class and `synthesizeCodingTaskContext` functional helper.
  </action>
  <verify>
    Run `pnpm exec tsc --noEmit` to verify type safety and schema validation logic.
  </verify>
  <done>
    TaskContextSynthesizer generates secure, sanitized, main-locked CodingTaskContext objects with formatted instructions.
  </done>
</task>
