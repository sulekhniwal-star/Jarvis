# Plan 31.2: Web UI Deployments Portal, Telegram /deploy Command & End-to-End Verification

## Objective
Construct the dedicated `/deployments` management portal, wire the Telegram `/deploy` command with promotion approval card dispatch, and verify end-to-end multi-environment deployment gating under `REQ-DEP-01` and `REQ-DEP-02`.

## Task Breakdown

### Task 1: Web UI Deployment Components & Portal
- Create `src/components/deployment/deployment-status-card.tsx`:
  - Displays current active production deployment status (emerald "Live Production"), production URL link (`https://jarvis.app`), deployed commit SHA badge, and latest preview URL.
  - Includes "Promote to Production" button and quick "Rollback" action.
- Create `src/components/deployment/production-promotion-modal.tsx`:
  - Accessible modal displaying target commit, commit message, verification proof summary, and "Request Production Approval" button.
- Create `src/components/deployment/deployments-table.tsx`:
  - Table of past preview and production deployments.
  - Environment badges (`preview` / `production`), status badges (`deployed`, `pending_approval`, `rolled_back`, `failed`).
  - Preview link triggers, approval details link, and inline "Rollback to this version" action.
- Create `src/components/deployment/deployments-view.tsx`:
  - Master container orchestrating `DeploymentStatusCard`, `DeploymentsTable`, `ProductionPromotionModal`, and state refresh.
- Create `src/app/deployments/page.tsx`:
  - Server-rendered page in `AppShell` with pre-fetched active deployment and deployment history.
- Update `src/components/layout/sidebar.tsx`:
  - Add `{ label: "Deployments", href: "/deployments", icon: Rocket }` to primary navigation.

### Task 2: Telegram Bot `/deploy` Command Integration
- Update `src/lib/telegram/commands.ts`:
  - Add `/deploy` command handler to `handleTelegramCommand` and `/start` help list.
  - Behavior:
    - `/deploy`: Displays active production deployment, live URL, deployed commit SHA, and latest preview URL in MarkdownV2.
    - `/deploy prod`: Initiates production promotion request and replies with the interactive approval card with HMAC-signed buttons.

### Task 3: Unit & Component Tests
- Create `tests/unit/components/deployment-view.test.tsx`:
  - Test `DeploymentStatusCard` rendering active production deployment and preview links.
  - Test `DeploymentsTable` environment filtering and status badges.
  - Test `ProductionPromotionModal` opening, input submission, and API dispatch.
  - Test rollback button dispatch.
- Create `tests/unit/telegram/deploy-command.test.ts`:
  - Test `/deploy` status reporting in MarkdownV2.
  - Test `/deploy prod` trigger creating approval request.

## Verification
- Run `cmd /c npx vitest run tests/unit/deployment tests/unit/api/deployments-routes.test.ts tests/unit/components/deployment-view.test.tsx tests/unit/telegram/deploy-command.test.ts`.
- Run full Vitest suite (`cmd /c npx vitest run`).
- Run Next.js production build (`cmd /c npm run build` with `BypassSandbox: true`).
