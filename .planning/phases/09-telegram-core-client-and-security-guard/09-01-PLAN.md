<task type="auto">
  <name>Author Telegram Bot API Client</name>
  <files>
    src/lib/telegram/client.ts
    tests/unit/telegram/client.test.ts
  </files>
  <action>
    1. Author `src/lib/telegram/client.ts`:
       - Class `TelegramClient`:
         - Constructor accepts optional `{ botToken?: string, baseUrl?: string }` (defaults to `process.env.TELEGRAM_BOT_TOKEN`).
         - `sendMessage(chatId, text, options)`: Calls `POST /sendMessage`.
         - `editMessageText(chatId, messageId, text, options)`: Calls `POST /editMessageText`.
         - `answerCallbackQuery(callbackQueryId, text?, showAlert?)`: Calls `POST /answerCallbackQuery`.
         - `getUpdates(options?)`: Calls `POST /getUpdates` with offset, limit, timeout.
         - `setWebhook(url, options?)`: Calls `POST /setWebhook` with secret_token.
         - `deleteWebhook(dropPendingUpdates?)`: Calls `POST /deleteWebhook`.
         - Validates responses; throws `TelegramApiError` on HTTP failures or `ok === false`.
    2. Author `tests/unit/telegram/client.test.ts`:
       - Mocks `globalThis.fetch` to test:
         - Successful `sendMessage` request payload and headers.
         - `editMessageText` request parameters.
         - `answerCallbackQuery` execution.
         - Error handling when Telegram returns `{ ok: false, error_code: 400, description: "Bad Request: chat not found" }`.
         - Network failure throwing appropriate error.
  </action>
</task>
