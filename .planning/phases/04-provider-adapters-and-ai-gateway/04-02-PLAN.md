<task type="auto">
  <name>Implement AIGateway with Free Failover and Paid Approval Gate</name>
  <files>
    src/lib/ai/gateway.ts
    .env.example
  </files>
  <action>
    1. Author `src/lib/ai/gateway.ts`:
       - `AIGateway` class:
         - Accepts `adapter: AIProviderAdapter`, `approvalRepo?: ApprovalRepository`, `ledgerService?: UsageLedgerService`, `budgetService?: BudgetService`.
         - Default free models list:
           - `meta-llama/llama-3.3-70b-instruct:free`
           - `google/gemini-2.0-flash-exp:free`
           - `qwen/qwen-2.5-coder-32b-instruct:free`
         - In `complete(request: AICompletionRequest)`:
           - Check model tier using `isFreeModel(model)`.
           - **If Paid Model:**
             - Enforce approval gate: Check for active, unexpired `paid_ai_inference` approval for `request.userId`.
             - If not approved, throw `PaidInferenceApprovalRequiredError`.
             - Check budget limits via `budgetService.checkBudgetLimits()`.
             - Dispatch request via adapter.
             - Record usage in `ledgerService`.
             - Return `AICompletionResponse`.
           - **If Free Model:**
             - Attempt primary requested free model (or default free model).
             - Catch 429 rate limit or 5xx server errors:
               - Log fallback attempt.
               - Iterate through remaining free models in the fallback chain.
             - If all free models fail, throw `AllFreeModelsExhaustedError` (DO NOT fall back to paid models automatically).
             - On success, record 0.00 cost usage in `ledgerService` and return response.
         - In `stream(request: AICompletionRequest)`:
           - Same approval and budget gate before initiating stream generator.
    2. Update `.env.example`:
       - Add `OPENROUTER_API_KEY=your_openrouter_api_key_here`
       - Add `USD_INR_EXCHANGE_RATE=84.0`
  </action>
  <verify>
    pnpm tsc --noEmit
  </verify>
  <done>
    AIGateway is fully implemented, respecting free failover chains and the paid approval barrier.
  </done>
</task>
