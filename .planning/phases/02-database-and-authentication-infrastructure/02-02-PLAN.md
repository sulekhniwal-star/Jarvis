<task type="auto">
  <name>Implement Supabase client factories, middleware, and Auth route handlers with unit tests</name>
  <files>
    src/lib/supabase/client.ts
    src/lib/supabase/server.ts
    src/lib/supabase/admin.ts
    src/lib/supabase/middleware.ts
    src/app/api/auth/callback/route.ts
    src/app/api/auth/login/route.ts
    src/app/api/auth/logout/route.ts
    src/app/api/auth/session/route.ts
    tests/unit/supabase/client.test.ts
    tests/unit/supabase/auth-routes.test.ts
  </files>
  <action>
    1. Implement `src/lib/supabase/client.ts`:
       - `createClient()` using `createBrowserClient<Database>` from `@supabase/ssr`.
    2. Implement `src/lib/supabase/server.ts`:
       - `createClient()` using `createServerClient<Database>` and `cookies()` from `next/headers` with cookie get/set/remove handlers.
    3. Implement `src/lib/supabase/admin.ts`:
       - `createAdminClient()` using `createClient<Database>` from `@supabase/supabase-js` with `SUPABASE_SERVICE_ROLE_KEY` and `{ auth: { persistSession: false } }`.
       - Protect with server-only check (`if (typeof window !== 'undefined') throw new Error(...)`).
    4. Implement `src/lib/supabase/middleware.ts`:
       - `updateSession(request: NextRequest)` refreshing Auth tokens and returning updated response with cookies.
    5. Implement Route Handlers:
       - `src/app/api/auth/callback/route.ts`: GET handler exchanging `code` query param for session via `supabase.auth.exchangeCodeForSession(code)`.
       - `src/app/api/auth/login/route.ts`: POST handler accepting email/password, returning user data or structured error.
       - `src/app/api/auth/logout/route.ts`: POST handler calling `supabase.auth.signOut()` and clearing session cookies.
       - `src/app/api/auth/session/route.ts`: GET handler returning current user profile or `{ authenticated: false }`.
    6. Author unit tests:
       - `tests/unit/supabase/client.test.ts`: Asserts client factories configure expected Supabase URLs, headers, and throws on client-side admin client access.
       - `tests/unit/supabase/auth-routes.test.ts`: Tests request handling, error responses on missing params, and response shapes.

    AVOID: Exposing `SUPABASE_SERVICE_ROLE_KEY` to client components.
    USE: `@supabase/ssr` recommended patterns for Next.js App Router.
  </action>
  <verify>
    pnpm test tests/unit/supabase/
    pnpm build
  </verify>
  <done>
    Client factories and Auth routes implemented, tested green with Vitest, and compiled cleanly with Next.js build.
  </done>
</task>
