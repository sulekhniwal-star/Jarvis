# Plan 36.2: Comprehensive Penetration Testing Suite, Secret Scanner Fuzzing & Security Audit Report

## Objective
Construct an automated penetration testing suite covering RLS tenant isolation, cryptographic timing-safety, path traversal containment, secret scanner fuzzing, and circuit breaker failsafes, culminating in `docs/SECURITY-AUDIT.md` verifying zero high or critical security vulnerabilities (`REQ-SEC-03`, `NFR-SEC-05`).

## Task Breakdown

### Task 1: Comprehensive Security Penetration Test Suite
- Create `tests/integration/security-penetration.test.ts`:
  - **Attack Vector 1: RLS Tenant Boundary Violations:**
    - Simulate client querying/mutating records belonging to another tenant (`user_b` accessing `user_a` project, task, or cost record).
    - Assert that Supabase RLS policies block unauthorized read, update, or deletion.
    - Assert that audit ledger records cannot be modified or deleted (`UPDATE` or `DELETE` blocked).
  - **Attack Vector 2: Timing Attack Side-Channel Simulation:**
    - Test HMAC approval token and webhook signatures against partially matching bytes.
    - Assert that `timingSafeEqual` evaluation executes constant-time byte comparisons.
  - **Attack Vector 3: Sandbox Path Traversal & File Escape Injections:**
    - Fuzz diff inspector with path traversal strings:
      - `../../etc/passwd`
      - `..\\..\\Windows\\System32\\cmd.exe`
      - `/var/log/syslog`
      - `C:/secrets.env`
      - `subfolder/../../../root.key`
    - Assert all are flagged as `PATH_TRAVERSAL_DETECTED` and rejected.
  - **Attack Vector 4: Multi-Format Secret Scanner Fuzzing:**
    - Fuzz secret scanner with synthetic tokens across 14 credential categories:
      - OpenAI API keys (`sk-proj-...`)
      - Stripe live secret keys (`sk_live_...`)
      - GitHub personal access tokens (`ghp_...`, `github_pat_...`)
      - AWS Access Key IDs & Secret Keys (`AKIA...`)
      - Database connection URIs (`postgres://...:secret@...`)
      - Slack bot tokens (`xoxb-...`)
      - High-entropy base64 and hex strings.
    - Assert 100% detection rate and verify non-secret standard code strings pass without false positives.
  - **Attack Vector 5: Financial Circuit Breaker & Spend Tampering:**
    - Attempt to invoke paid inference with missing cost repo, verifying failsafe lock.
    - Attempt to invoke paid inference after daily (₹25) and monthly (₹750) limits are tripped.
    - Assert zero unmetered leakage.
  - **Attack Vector 6: Kill-Switch Stress Test Under Concurrency:**
    - Register multiple concurrent child processes.
    - Execute emergency stop concurrently; assert idempotency and sub-second termination (<1.0s).

### Task 2: Master Security Audit Documentation
- Create `docs/SECURITY-AUDIT.md`:
  - Document complete threat model and security architecture.
  - Include 14-table RLS policy matrix and enforcement mechanisms.
  - Document cryptographic validation standards (HMAC-SHA256, constant-time equality).
  - Detail path traversal defenses, secret scanning patterns, and circuit breaker financial controls.
  - Certify 0 P0/P1 high/critical vulnerabilities (`NFR-SEC-05`).
