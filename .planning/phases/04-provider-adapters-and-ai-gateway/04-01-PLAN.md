<task type="auto">
  <name>Implement OpenRouter Adapter and Offline Mock Adapter</name>
  <files>
    src/lib/ai/adapters/openrouter.ts
    src/lib/ai/adapters/mock.ts
  </files>
  <action>
    1. Author `src/lib/ai/adapters/openrouter.ts`:
       - Extends or implements `AIProviderAdapter`.
       - Reads `OPENROUTER_API_KEY` from environment or constructor options.
       - Sends required headers:
         - `Authorization: Bearer ${apiKey}`
         - `HTTP-Referer: https://jarvis.internal`
         - `X-Title: Jarvis AI Assistant`
         - `Content-Type: application/json`
       - In `complete()`:
         - Sets `response_format: { type: "json_object" }` if `request.responseFormat === 'json'`.
         - Measures latency in milliseconds.
         - Parses response choices and token usage.
         - Normalizes HTTP error responses (429 Rate Limit, 5xx Provider Outage).
       - In `stream()`:
         - Uses `fetch` with `ReadableStream` reader.
         - Parses Server-Sent Events (`data: {...}`, `data: [DONE]`).
         - Yields `AIStreamChunk`.
    2. Author `src/lib/ai/adapters/mock.ts`:
       - Implements `AIProviderAdapter` for unit testing and offline development.
       - Configurable pre-programmed responses, simulated latency, token counts, and error simulation (e.g. simulated 429 for fallback testing).
  </action>
  <verify>
    pnpm tsc --noEmit
  </verify>
  <done>
    Both adapters implement AIProviderAdapter interface and compile cleanly.
  </done>
</task>
