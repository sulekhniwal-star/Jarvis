<task type="auto">
  <name>Create match_memories RPC Migration and Embedding Service</name>
  <files>
    supabase/migrations/20261116000001_match_memories_rpc.sql
    src/lib/ai/embedding-service.ts
  </files>
  <action>
    1. Create `supabase/migrations/20261116000001_match_memories_rpc.sql`:
       - Define `match_memories(query_embedding vector(1536), match_threshold float, match_count int, filter_user_id uuid, filter_project_id uuid, filter_category text)`
       - Compute cosine similarity `1 - (m.embedding <=> query_embedding)`
       - Filter by user_id, project_id (matching project or null/global), category, and match_threshold
       - Order by `m.embedding <=> query_embedding` ascending, limit to `match_count`
    2. Create `src/lib/ai/embedding-service.ts`:
       - Class `EmbeddingService` with `generateEmbedding(text: string): Promise<number[]>`
       - Call OpenRouter `/api/v1/embeddings` with `text-embedding-3-small` if apiKey present
       - Provide `deterministicLocalEmbedding(text: string): number[]`:
         - 1536 dimensions, unit-normalized Euclidean length (sum of squares = 1)
         - Seeded hash accumulation from words and character n-grams
       - Provide helper `cosineSimilarity(vecA: number[], vecB: number[]): number`
  </action>
  <verify>
    Create unit tests in `tests/unit/ai/embedding-service.test.ts` verifying 1536 dimension, unit length, deterministic matching, and cosine similarity helper.
  </verify>
</task>

    1. Create `src/lib/repositories/memory-repository.ts` extending `BaseRepository`:
       - Types: `CreateMemoryDTO`, `UpdateMemoryDTO`, `MemoryListFilters`, `SemanticSearchParams`
       - `createMemory(dto: CreateMemoryDTO): Promise<Memory>`: generates embedding via `EmbeddingService` if not provided, inserts into `public.memories`
       - `getById(id: string): Promise<Memory | null>`
       - `listMemories(filters: MemoryListFilters): Promise<{ data: Memory[]; total: number }>`: filters by user_id, category, project_id, search term, with pagination
       - `searchSimilarMemories(params: SemanticSearchParams): Promise<Array<Memory & { similarity: number }>>`:
         - Encodes query text with `EmbeddingService`
         - Attempts `client.rpc('match_memories', ...)`
         - Falls back gracefully to candidate retrieval + in-memory cosine ranking if RPC fails or in mock environment
       - `updateMemory(id: string, userId: string, data: UpdateMemoryDTO): Promise<Memory>`
       - `deleteMemory(id: string, userId: string): Promise<boolean>`
  </action>
  <verify>
    Create unit tests in `tests/unit/repositories/memory-repository.test.ts` verifying CRUD operations, filtering, and semantic search.
  </verify>
