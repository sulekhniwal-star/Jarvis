# Plan 29.2: Web Topbar Emergency Stop UI, Telegram /kill Integration & Verification

## Objective
Build the client-side emergency stop UI in the Web topbar, wire the `/kill` Telegram bot command with sub-second response formatting, and verify complete system halting across all channels.

## Task Breakdown

### Task 1: Telegram Bot `/kill` Command Integration (`REQ-SEC-01`, `NFR-PERF-03`)
- Update `src/lib/telegram/commands.ts`:
  - Add `/kill` command to `handleTelegramCommand` and `/start` help listing.
  - Invokes `EmergencyKillSwitchService.executeEmergencyStop(userId, "telegram")`.
  - Formats immediate high-priority alert in MarkdownV2:
    - Reports: Terminated processes, cancelled runs, cancelled tasks, revoked approvals, and elapsed duration in milliseconds (`⚡ Terminated in X ms (< 1000ms nominal)`).

### Task 2: Web Topbar Emergency Stop Button & Alert Banner (`REQ-SEC-01`)
- Create `src/components/system/emergency-stop-button.tsx`:
  - High-visibility emergency stop trigger button with `OctagonAlert` icon in Topbar.
  - Confirmation modal warning the owner of instant cancellation of all active processes, agent runs, and pending approvals.
  - Submits to `POST /api/system/kill` with source `"web"`.
  - On execution, triggers callback and opens emergency alert banner.
- Create `src/components/system/emergency-alert-banner.tsx`:
  - Persistent alert banner displayed at the top of the interface when an emergency stop has been executed, reporting termination summary and timestamp.
- Modify `src/components/layout/topbar.tsx`:
  - Mount `EmergencyStopButton` directly adjacent to status badges.

### Task 3: Unit & Component Tests
- Create `tests/unit/telegram/kill-command.test.ts`:
  - Test `/kill` parsing, dependency invocation, markdown formatting, and duration reporting.
- Create `tests/unit/components/emergency-stop.test.tsx`:
  - Test button rendering, modal opening, confirmation submission, and alert banner display.

## Verification
- Run `cmd /c npx vitest run tests/unit/telegram/kill-command.test.ts tests/unit/components/emergency-stop.test.tsx`.
- Run full Vitest suite (`cmd /c npx vitest run`).
- Run Next.js production build (`cmd /c npm run build` with `BypassSandbox: true`).
