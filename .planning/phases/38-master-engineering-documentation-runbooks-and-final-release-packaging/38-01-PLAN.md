# Plan 38.1: Operational Runbooks, Release Verification Runner & Readiness Test Suite

## Objective
Author complete operational runbooks for emergency response, disaster recovery, and production deployments, implement an automated release verification script (`scripts/release-verify.ts`), and validate release readiness via automated integration tests (`REQ-REL-01`, `NFR-QUAL-01`).

## Task Breakdown

### Task 1: Operational Runbooks
- Create `docs/runbooks/EMERGENCY_OPERATIONS.md`:
  - Detailed operational instructions for emergency stop execution across Web, Telegram (`/kill`), and REST API.
  - Sub-second process cancellation mechanics and cascading state cleanups.
  - Post-incident recovery checklist and circuit breaker re-initialization.
- Create `docs/runbooks/DISASTER_RECOVERY.md`:
  - Automated backup snapshot configuration, encryption keys, and checksum validation.
  - Step-by-step restoration procedure adhering to topological foreign key ordering.
  - Zero-loss table parity verification drill execution.
- Create `docs/runbooks/PRODUCTION_RELEASE_GUIDE.md`:
  - Pre-deployment gating checklist (branch hygiene, test suite, secret scanning, diff quality).
  - Preview environment URL generation and health inspection.
  - Unified Approval Centre HMAC-SHA256 promotion procedure.
  - 1-Click rollback execution protocol.

### Task 2: Automated Release Verification Runner
- Create `scripts/release-verify.ts`:
  - Implements `ReleaseReadinessVerifier` executing 5 production gates:
    1. Branch safety invariant: verifies local branch is strictly `main`.
    2. Security controls: executes `SecurityAuditSuite.runFullSecurityAudit()`.
    3. Accessibility standards: executes `AccessibilityAuditor.generateComplianceReport()`.
    4. System diagnostics: probes database and AI gateway liveness.
    5. Release packaging integrity: asserts `package.json` version is `10.0.0`.
  - Can be invoked via CLI (`npm run release:verify`) or programmatically.
- Modify `package.json`:
  - Add `"release:verify": "tsx scripts/release-verify.ts"`.

### Task 3: Release Readiness Integration Test Suite
- Create `tests/integration/release-readiness.test.ts`:
  - Test executing `ReleaseReadinessVerifier` with clean git and mock services.
  - Test verifying failure when branch hygiene is violated (non-main branch).
  - Test verifying failure when security audit fails.
  - Test verifying failure when accessibility contrast is non-compliant.

## Verification
- Run `cmd /c npx vitest run tests/integration/release-readiness.test.ts`.
- Run `npm run release:verify` via `cmd /c tsx scripts/release-verify.ts`.
