<task type="auto">
  <name>Implement Next.js Webhook Route Handler</name>
  <files>
    src/app/api/telegram/webhook/route.ts
    tests/unit/api/telegram-webhook-route.test.ts
  </files>
  <action>
    1. Author `src/app/api/telegram/webhook/route.ts`:
       - `POST` route handler:
         - Verifies `X-Telegram-Bot-Api-Secret-Token` header using `verifyWebhookSecret`. If invalid, returns 401 Unauthorized.
         - Parses request JSON as `TelegramUpdate`.
         - Validates sender authorization using `isAuthorizedSender`. If unauthorized, logs warning and returns 200 `{ ok: true, dropped: true }` (preventing Telegram retry spam while leaking zero data).
         - If `update.message?.text`:
           - If text starts with `/`, dispatches `handleTelegramCommand(text)` and sends reply using `TelegramClient.sendMessage`.
           - If text is natural language (non-command), sends acknowledgment message indicating task intake is active.
         - Returns 200 `{ ok: true }`.
    2. Author `tests/unit/api/telegram-webhook-route.test.ts`:
       - Test 1: Rejects requests with invalid secret token (401).
       - Test 2: Drops updates from unauthorized `from.id` and returns 200 without sending messages.
       - Test 3: Processes `/start` command for authorized owner and invokes `sendMessage`.
       - Test 4: Processes non-command text and responds with intake acknowledgment.
  </action>
</task>

<task type="auto">
  <name>Author Dev Long-Polling Runner Script</name>
  <files>
    scripts/telegram-polling.ts
  </files>
  <action>
    Author `scripts/telegram-polling.ts`:
    - Standalone runner script executable with `pnpm exec tsx scripts/telegram-polling.ts`.
    - Checks required env vars (`TELEGRAM_BOT_TOKEN`, `OWNER_TELEGRAM_ID`).
    - Calls `telegramClient.deleteWebhook({ dropPendingUpdates: false })` on startup.
    - Loops `getUpdates({ offset, timeout: 30 })` with graceful SIGINT / SIGTERM shutdown.
    - For each update, checks authorization via `isAuthorizedSender` and routes messages through `handleTelegramCommand`.
    - Logs concise console status for local debugging.
  </action>
</task>
