<task type="auto">
  <name>Implement ExecutionCoordinator with State Machine Transitions</name>
  <files>
    src/lib/agents/engine/telemetry/execution-coordinator.ts
  </files>
  <action>
    Create `src/lib/agents/engine/telemetry/execution-coordinator.ts`:
    1. Class `ExecutionCoordinator`:
       - Injects `taskRepo: TaskRepository`, `runRepo: AgentRunRepository`, `orchestrator: SandboxOrchestrator`, `pipeline: ArtifactPipeline`.
       - `executeTaskStep(params: CoordinatorExecutionParams): Promise<ExecutionRunSummary>`:
         - Creates run in `runRepo.createRun(taskId, "aider")` (`queued`).
         - Transitions `taskRepo.updateStatus(taskId, "running")`.
         - Starts run in `runRepo.startRun(runId)`.
         - Synthesizes `context` via `synthesizeCodingTaskContext`.
         - Dispatches execution via `orchestrator.execute(context)`.
         - If result is success:
           - Transitions run via `runRepo.completeRun(runId, { exitCode: 0, commitHash, diffPatch, testResults })`.
           - Transitions task via `taskRepo.updateStatus(taskId, "completed")`.
         - If result is failure:
           - Transitions run via `runRepo.failRun(runId, exitCode, errorDetails)`.
           - Transitions task via `taskRepo.updateStatus(taskId, "failed")`.
         - Persists artifacts via `pipeline.recordArtifacts`.
         - Returns `ExecutionRunSummary`.
  </action>
  <verify>
    Run `pnpm.cmd exec tsc --noEmit` to verify coordinator logic.
  </verify>
  <done>
    ExecutionCoordinator manages the complete task lifecycle with state machine transitions.
  </done>
</task>
