  <name>Create Task Mutation API Routes</name>
  <files>

    src/app/api/tasks/[id]/route.ts
  </files>
  <action>
    1. Create `src/app/api/projects/[id]/tasks/route.ts`:
       - `POST`: Authenticate session, parse Zod body (`title`, `description`, `priority`, `riskLevel`, `estimatedCostInr`, `milestoneId`), call `TaskRepository.create()`, return 201 with created task.
    2. Create `src/app/api/tasks/[id]/route.ts`:
       - `GET`: Authenticate session, retrieve task by ID with its linked specification (from `SpecificationRepository`), linked plan (from `PlanRepository`), and latest agent runs.
       - `PATCH`: Authenticate session, parse Zod body (`status`, `priority`, `milestoneId`, `title`, `description`), validate status change with `TaskStateMachine.assertTransition(currentStatus, targetStatus)`, call `TaskRepository.updateStatus()` or `TaskRepository.update()`, and return updated task.
  </action>
  <verify>
    Create unit tests in `tests/unit/api/tasks-update-route.test.ts` verifying task creation, invalid state transition rejection (400), valid transition success (200), and task detail retrieval with linked spec/plan.
  </verify>
</task>

       - Render task title, priority badge with Jarvis color tokens (`urgent`: red, `high`: amber, `medium`: cyan, `low`: slate), risk level indicator, milestone pill, and cost estimate.
       - Render status badge and quick transition buttons for legal next states according to `TaskStateMachine`.

    2. Create `src/components/projects/project-kanban-board.tsx`:
       - 4 columns:
         - **Backlog** (`intake`, `specifying`, `planned`)

         - **Review & Blocked** (`awaiting_approval`, `failed`, `cancelled`)
         - **Completed** (`completed`)
       - Column headers showing count badges and accent colors.
       - Empty state for empty columns.
       - Optimistic task status updates with error rollback if API request fails.
    3. Create `src/components/projects/create-task-modal.tsx`:
       - Form fields: Task title, description, priority select, risk level select, estimated cost (INR), milestone selector dropdown.
       - Handles validation, submission to `POST /api/projects/[id]/tasks`, and optimistic append to task list.
  </action>
  <verify>
    Create unit tests in `tests/unit/components/project-kanban.test.tsx` verifying column filtering, task card rendering, and status transition interactions.
