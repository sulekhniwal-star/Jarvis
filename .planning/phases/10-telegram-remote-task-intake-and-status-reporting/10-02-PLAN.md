  <name>Extend TelegramIntakeService with Clarification Handler</name>
  <files>
    src/lib/telegram/intake.ts
    tests/unit/telegram/clarification.test.ts
  </files>
  <action>
    1. Update `src/lib/telegram/intake.ts`:
       - `getActiveClarificationSession(userId: string): Promise<ActiveClarificationSession | null>`
       - `handleClarificationAnswer(userId: string, answerText: string): Promise<string>`:
         - Maps `answerText` to pending questions in conversation metadata.
         - Calls `specifierAgent.specifyWithClarifications(originalPrompt, answers)`.
         - If still needs clarification and `round < 3`:
           - Updates metadata with round + 1, new questions, and returns formatted questions.
         - If `specified` (or round >= 3 with best effort):
           - Persists specification via `SpecificationRepository.createDraft`.
           - Updates conversation metadata: `awaitingClarification: false, completed: true`.
           - Returns formatted specification ready card.
       - `cancelClarification(userId: string): Promise<string>`:
         - Finds active conversation with `awaitingClarification: true`.
         - Updates metadata: `awaitingClarification: false, cancelled: true`.
         - Returns cancellation confirmation message.
    2. Author `tests/unit/telegram/clarification.test.ts`:
       - Tests answering a clarification question successfully produces a specification.
       - Tests multi-round clarification progression.
       - Tests canceling an active clarification session.
  </action>
</task>
