# Plan 35.1: 10-Stage Autonomous Lifecycle Integration Orchestrator & E2E Test Suite

## Objective
Construct `AutonomousLifecycleHarness` in `src/lib/testing/e2e-harness.ts` to orchestrate and validate the complete 10-stage autonomous software engineering workflow (`REQ-SYS-01`), backed by a comprehensive end-to-end integration test suite (`tests/integration/autonomous-lifecycle.test.ts`).

## Task Breakdown

### Task 1: End-to-End Autonomous Lifecycle Harness
- Create `src/lib/testing/e2e-harness.ts`:
  - Define `LifecycleExecutionState`:
    - `taskId: string`
    - `specification: Specification`
    - `clarificationAnswers: Record<string, string>`
    - `plan: ExecutionPlan`
    - `planApprovalId: string`
    - `agentRunId: string`
    - `verificationReport: VerificationReport`
    - `diffInspection: DiffQualityReport`
    - `pushApprovalId: string`
    - `previewDeploymentId: string`
    - `productionDeploymentId: string`
    - `auditChainVerification: AuditChainVerificationResult`
    - `diagnosticsReport: SystemHealthReport`
  - Implement `AutonomousLifecycleHarness`:
    - `runFullLifecycle(initialPrompt, options)`:
      - Stage 1: Ingests user prompt via `SpecifierAgent`.
      - Stage 2: Clarification Q&A resolution if underspecified.
      - Stage 3: Synthesizes structured `Specification` with acceptance criteria.
      - Stage 4: Decomposes specification into atomic tasks via `PlannerAgent`.
      - Stage 5: Gated plan review with HMAC decision verification.
      - Stage 6: Executes code change via mock coding agent in sandbox.
      - Stage 7: Evaluates verification harness (tests, lint, tsc), diff inspector, and secret scanner.
      - Stage 8: Gated git push with owner approval.
      - Stage 9: Deploys preview URL, submits production promotion request, approves, and marks deployed.
      - Stage 10: Verifies tamper-evident audit ledger chain head, probes system health, and collects proactive advisory recommendations.
    - Returns structured `LifecycleSummaryReport` containing execution metrics, stage latencies, and verification artifacts.

### Task 2: End-to-End Integration Test Suite
- Create `tests/integration/autonomous-lifecycle.test.ts`:
  - Test executing full 10-stage lifecycle from natural language prompt to production deployment.
  - Test data flow consistency across stages (task ID, spec ID, run ID, approval IDs, commit SHA).
  - Test HMAC decision signature verification at all human-in-the-loop gates.
  - Test tamper-evident audit chain mathematical continuity across all recorded events.

## Verification
- Run `cmd /c npx vitest run tests/integration/autonomous-lifecycle.test.ts`.
