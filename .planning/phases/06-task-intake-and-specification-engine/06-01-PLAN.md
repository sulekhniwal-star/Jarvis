<task type="auto">
  <name>Author Specifier prompt templates and system directives</name>
  <files>
    src/lib/agents/specifier/prompts.ts
  </files>
  <action>
    Author `src/lib/agents/specifier/prompts.ts`:
    - `SPECIFIER_SYSTEM_PROMPT`: Directs the LLM to behave as a senior requirements engineer and software architect. Instructs on:
      1. Analyzing raw prompts against the project context.
      2. Scoring ambiguity across 4 dimensions: Goal Clarity (0.35), Technical Boundaries (0.25), Acceptance Measurability (0.25), Preconditions (0.15).
      3. Calculating weighted ambiguity score (0.0 to 1.0).
      4. If score > 0.35, outputting status "needs_clarification" with 1 to 3 concise, high-leverage Socratic questions.
      5. If score <= 0.35, outputting status "specified" with detailed scope, explicit exclusions (non-goals), and testable Given-When-Then acceptance criteria.
      6. Outputting strictly valid JSON conforming to the schema.
    - Helper formatting functions:
      - `formatUserPromptWithContext(input: SpecifierInput): string`: Formats the user's prompt, project info, and optional past clarification Q&A history.
  </action>
</task>

<task type="auto">
  <name>Implement Specifier Agent class with AIGateway integration</name>
  <files>
    src/lib/agents/specifier/specifier-agent.ts
  </files>
  <action>
    Author `src/lib/agents/specifier/specifier-agent.ts`:
    - Define `SpecifierAgent` class accepting `AIGateway` in constructor.
    - Method `specify(input: SpecifierInput): Promise<SpecifierAgentResponse>`:
      1. Constructs prompt messages with system prompt and formatted user input.
      2. Calls `AIGateway.complete({ messages, responseFormat: 'json', userId: input.userId })`.
      3. Parses completion response using `JSON.parse` with error handling.
      4. Validates parsed payload against `SpecifierAgentResponseSchema.parse()`.
      5. If validation fails, attempts a repair or surfaces descriptive error.
      6. Returns strongly-typed `SpecifierAgentResponse`.
    - Method `specifyWithClarifications(input: SpecifierInput, answers: ClarificationAnswer[]): Promise<SpecifierAgentResponse>`:
      Appends clarification Q&A history into conversational messages and re-dispatches to produce a refined or finalized specification.
  </action>
</task>
