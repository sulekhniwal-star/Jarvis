<task type="auto">
  <name>Author Telegram Intake Service</name>
  <files>
    src/lib/telegram/intake.ts
    src/lib/telegram/index.ts
  </files>
  <action>
    1. Author `src/lib/telegram/intake.ts`:
       - Define interface `IntakeDependencies` allowing injection of:
         - `specifierAgent`: SpecifierAgent
         - `taskRepo`: TaskRepository
         - `specRepo`: SpecificationRepository
         - `convRepo`: ConversationRepository
         - `projectRepo`: ProjectRepository
         - `client`: TelegramClient
       - Class `TelegramIntakeService`:
         - `handleNewTaskPrompt(userId: string, chatId: number | string, prompt: string): Promise<string>`:
           1. Resolves active project for user via `projectRepo` (e.g. latest created project, or creates default "Personal Workspace" if none).
           2. Creates new task in `public.tasks` with `title` (truncated prompt), `status: 'specifying'`, `priority: 'medium'`.
           3. Calls `specifierAgent.specify(prompt)`.
           4. If `response.status === 'needs_clarification'`:
              - Creates/updates conversation in `public.conversations` with `channel: 'telegram'`, `status: 'active'`, and `metadata: { taskId, awaitingClarification: true, originalPrompt: prompt, questions: response.questions, round: 1 }`.
              - Returns formatted MarkdownV2 string listing Socratic questions with instructions on how to reply or `/cancel`.
           5. If `response.status === 'specified'`:
              - Persists specification in `public.specifications` via `SpecificationRepository.createDraft(taskId, response.specification)`.
              - Returns formatted MarkdownV2 confirmation card with scope, acceptance criteria count, and next steps.
    2. Export `TelegramIntakeService` and related types in `src/lib/telegram/index.ts`.
  </action>
</task>
