# Plan 11.1: Interactive Approval Card Formatting & Delivery Service

Implement MarkdownV2 formatting and delivery services for interactive Telegram approval cards for execution plans and sensitive actions, including inline button keyboards (`[ ✅ Approve ]`, `[ ❌ Reject ]`) complying with Telegram Bot API payload limits (`REQ-TG-05`).

  <name>Author Approval Card Formatting and Delivery Service</name>
  <files>

  <action>
    1. Author `src/lib/telegram/approvals.ts`:
       - Define types:
         - `PlanApprovalCardData`: `{ plan: Plan; task?: Task }`
         - `ActionApprovalCardData`: `{ approval: Approval; task?: Task }`
         - `ApprovalDecisionType`: `'approved' | 'rejected'`
       - Formatting functions:
         - `formatPlanApprovalCard(data: PlanApprovalCardData): { text: string; replyMarkup: InlineKeyboardMarkup }`:
           - Formats title with emoji `🚨 APPROVAL REQUIRED: Execution Plan`
           - Formats Task title, Plan version, Steps count, Risk level badge, and estimated cost if present.
           - Builds `inline_keyboard`:
             `[ [ { text: "✅ Approve Plan", callback_data: `appr:plan:${plan.id}` }, { text: "❌ Reject", callback_data: `rejc:plan:${plan.id}` } ] ]`
         - `formatActionApprovalCard(data: ActionApprovalCardData): { text: string; replyMarkup: InlineKeyboardMarkup }`:
           - Formats title with emoji `🚨 APPROVAL REQUIRED: Sensitive Action`
           - Displays action type (e.g. `git_remote_push`, `production_deploy`), target resource, and description.
           - Builds `inline_keyboard`:
             `[ [ { text: "✅ Approve", callback_data: `appr:act:${approval.id}` }, { text: "❌ Reject", callback_data: `rejc:act:${approval.id}` } ] ]`
         - `formatDecisionReceipt(type: "plan" | "action", title: string, decision: ApprovalDecisionType, decidedAt: Date, notes?: string): string`:
           - Formats MarkdownV2 immutable confirmation receipt with timestamp and decision icon (`✅ APPROVED` / `❌ REJECTED`).
       - Service class `TelegramApprovalService`:
         - Constructor accepting optional `TelegramClient`.
         - `sendPlanCard(chatId: number | string, data: PlanApprovalCardData): Promise<TelegramMessage>`
         - `sendActionCard(chatId: number | string, data: ActionApprovalCardData): Promise<TelegramMessage>`
    2. Export `TelegramApprovalService`, formatters, and types in `src/lib/telegram/index.ts`.
  </action>
</task>
