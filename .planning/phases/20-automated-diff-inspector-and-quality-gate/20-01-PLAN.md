<task type="auto">
  <name>Implement Unified Diff Parser, Boundary Validator & Quality Scorer</name>
  <files>
    src/lib/agents/engine/verification/diff-inspector/diff-parser.ts
    src/lib/agents/engine/verification/diff-inspector/boundary-validator.ts
    src/lib/agents/engine/verification/diff-inspector/quality-scorer.ts
  </files>
  <action>
    1. Create `src/lib/agents/engine/verification/diff-inspector/diff-parser.ts`:
       - Implement `parseUnifiedDiff(rawDiff: string): DiffFile[]`.
       - Handles `diff --git a/... b/...`, `new file mode`, `deleted file mode`, `rename from/to`, hunk headers `@@ ... @@`, and additions/deletions.
    2. Create `src/lib/agents/engine/verification/diff-inspector/boundary-validator.ts`:
       - Implement `validateFileBoundaries(files: DiffFile[], allowedPatterns: string[], allowDeletions: boolean = false): DiffViolation[]`.
       - Normalizes paths and matches exact files, directory prefixes, and glob wildcards (`*`, `**`).
       - Flags any file outside allowed boundaries as `UNAUTHORIZED_FILE_MUTATION` (severity: `blocker`).
       - Flags any unexpected file deletion as `UNAUTHORIZED_FILE_DELETION` (severity: `blocker`).
    3. Create `src/lib/agents/engine/verification/diff-inspector/quality-scorer.ts`:
       - Implement `scoreDiffQuality(files: DiffFile[]): { metrics: DiffQualityMetrics; violations: DiffViolation[] }`.
       - Calculates additions, deletions, total churn, and risk tier (`low`, `medium`, `high`, `extreme`).
       - Scans added lines for debug residue (`console.log`, `debugger;`, `print(`, `TODO: remove`) and produces `DEBUG_RESIDUE_DETECTED` warnings.
       - Generates warning for excessive single-file churn (> 500 lines).
  </action>
  <verify>
    Run `pnpm.cmd exec tsc --noEmit` to verify parser and scorer implementation.
  </verify>
  <done>
    Diff parser, boundary validator, and quality scorer are implemented and type checked.
  </done>
</task>
