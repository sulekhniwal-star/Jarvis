## Tasks

<task type="auto">
  <name>Enhance GET /api/agents/runs with Filters and Metrics</name>
  <files>
    src/app/api/agents/runs/route.ts
  </files>
  <action>
    1. Upgrade `GET /api/agents/runs` in `src/app/api/agents/runs/route.ts`:
       - Extract query parameters: `status`, `agentEngine`, `search`, `limit` (default 50), `offset` (default 0).
       - Query agent runs with optional status/engine filters.
       - Enrich each run with task title, task priority, and project name/slug by joining through `tasks` and `projects`.
       - Compute aggregate metrics across runs:
         - `totalRuns`: total count
         - `activeRuns`: count of status `queued` or `running`
         - `completedRuns`: count of status `completed`
         - `failedRuns`: count of status `failed`
         - `successRate`: `completed / (completed + failed) * 100` (or 100% if none)
         - `avgDurationMs`: average execution duration in milliseconds
       - Return `{ runs, total, limit, offset, metrics }`.
  </action>
  <verify>
    Create unit tests in `tests/unit/api/agents-runs-api.test.ts` verifying filtering, metrics calculation, and task/project metadata enrichment.
  </verify>
</task>
