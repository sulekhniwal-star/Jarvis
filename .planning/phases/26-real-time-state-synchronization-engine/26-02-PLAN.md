# Plan 26.2: Domain Hooks, UI Synchronizers & Realtime Status Indicator

## Objective
Wire real-time state synchronizers into the Project Kanban workspace, Agent Operations Console, and Dashboard cards, and provide a live visual connection status indicator in the topbar.

## Task Breakdown

### Task 1: Domain-Specific Synchronizer Hooks
- Create `src/hooks/use-realtime-tasks.ts`:
  - Maintains `tasks` state for a given `projectId` or all tasks.
  - Handles `INSERT`, `UPDATE`, and `DELETE` events from Supabase Realtime.
  - Supports optimistic status transitions: updates state immediately, reconciles when server event arrives, rolls back on error.
  - Integrates fallback polling via `/api/projects/[id]/tasks` or `/api/tasks`.
- Create `src/hooks/use-realtime-runs.ts`:
  - Maintains agent runs state and recalculates aggregate metrics (total, active, success rate %, avg duration).
  - Handles real-time status transitions (`queued` -> `running` -> `completed` / `failed`).
  - Integrates fallback polling via `/api/agents/runs`.
- Create `src/hooks/use-realtime-approvals.ts`:
  - Maintains pending approvals state.
  - Automatically updates badge counts and removes approval cards immediately upon decision.

### Task 2: Realtime Status Badge Component
- Create `src/components/layout/realtime-status-badge.tsx`:
  - Renders connection status:
    - `Live`: Emerald green badge with pulsing dot and tooltip ("Real-time WebSocket connected").
    - `Polling`: Amber badge with sync icon and tooltip ("Reconnecting — Fallback polling active (12s)").
    - `Offline`: Slate gray badge with alert icon and tooltip ("Network offline").
  - Accessible `role="status"` and `aria-live="polite"`.

### Task 3: UI Integration
- Update `src/components/layout/topbar.tsx`:
  - Replace static `Online` badge with `RealtimeStatusBadge`.
- Update `src/components/projects/project-workspace-view.tsx`:
  - Connect `useRealtimeTasks` so Kanban columns, task counters, and velocity update live without page refresh.
- Update `src/components/agents/agents-console-view.tsx` & `src/components/dashboard/agent-runs-card.tsx`:
  - Connect `useRealtimeRuns` for live agent execution updates.
- Update `src/components/dashboard/pending-approvals-card.tsx`:
  - Connect `useRealtimeApprovals` for instant approval state updates.

### Task 4: Unit & Integration Tests
- Create `tests/unit/hooks/use-realtime-domain-hooks.test.ts`:
  - Test task state mutation on real-time INSERT/UPDATE/DELETE.
  - Test agent runs status transitions and metric updates.
  - Test approval item dismissal upon real-time event.
- Create `tests/unit/components/realtime-status-badge.test.tsx`:
  - Test rendering in connected, polling, and offline states.
