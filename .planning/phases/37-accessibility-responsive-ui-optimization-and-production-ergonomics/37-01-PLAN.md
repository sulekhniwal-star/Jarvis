# Plan 37.1: WCAG 2.1 AA Accessibility Standards, Focus Rings & Navigation Ergonomics

## Objective
Enforce WCAG 2.1 AA accessibility standards across navigation and layout, establish the missing `/tasks` page to ensure zero broken navigation paths, and add visible focus indicators and reduced-motion support (`REQ-UI-01`, `NFR-A11Y-01`).

## Task Breakdown

### Task 1: Complete Tasks Backlog View (`src/app/tasks/page.tsx`)
- Create `src/app/tasks/page.tsx`:
  - Mount inside `AppShell` with `title="Tasks Backlog"`.
  - Provide search input with `aria-label="Search tasks"`.
  - Status filter tabs: `all`, `planned`, `running`, `completed`, `failed`.
  - Render accessible task cards displaying:
    - Task title, project name, status badge, priority indicator.
    - Accessible link to task plan review (`/tasks/[id]/plan`).
  - Empty state with clear messaging when zero tasks match filter.

### Task 2: Navigation Landmarks, Focus Rings & Reduced Motion
- Modify `src/components/layout/sidebar.tsx`:
  - Use `aria-current="page"` on the active navigation link.
  - Add explicit `aria-label` on navigation elements and badge counters (`aria-label="3 pending approvals"`).
- Modify `src/components/layout/topbar.tsx`:
  - Add `role="banner"` to the topbar container.
  - Add `aria-label="Open mobile navigation menu"` to mobile menu toggle button.
  - Add `aria-label="Emergency Kill Switch"` to kill switch trigger.
- Modify `src/components/layout/mobile-nav.tsx`:
  - Add `aria-modal="true"`, `role="dialog"`, and `aria-label="Mobile Navigation"`.
  - Add `aria-label="Close mobile navigation menu"` on the close button.
  - Trap focus and support `Escape` key dismissal.
- Modify `src/app/globals.css`:
  - Add `@media (prefers-reduced-motion: reduce)` block disabling animations, smooth scrolling, and transitions.

### Task 3: Unit Test Suite
- Create `tests/unit/components/accessibility-standards.test.tsx`:
  - Test skip-to-main-content link is present and targets `#main-content`.
  - Test landmark roles: `role="banner"`, `role="main"`, `nav[aria-label="Sidebar Navigation"]`.
  - Test active link renders `aria-current="page"`.
  - Test mobile menu and drawer accessibility attributes (`role="dialog"`, `aria-label`, escape key).
  - Test `/tasks` page renders accessible controls and search input.

## Verification
