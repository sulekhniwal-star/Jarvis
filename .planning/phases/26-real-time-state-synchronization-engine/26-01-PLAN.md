# Plan 26.1: Realtime Core Engine, Publications Migration, Fallback Polling & Base Hooks

## Objective
Establish the database publication configuration, multiplexed channel connection manager, and resilient base React hooks supporting Supabase Realtime `postgres_changes` with automatic fallback polling upon disconnection.

## Task Breakdown

### Task 1: Supabase Realtime Publication Migration
- Create `supabase/migrations/20261117000001_realtime_publications.sql`:
  - Register `tasks`, `agent_runs`, `projects`, and `approvals` tables to the `supabase_realtime` publication.
  - Set `REPLICA IDENTITY FULL` where appropriate to provide full old and new records during UPDATE/DELETE operations.

### Task 2: Realtime Types & Interfaces
- Create `src/lib/realtime/types.ts`:
  - `RealtimeStatus = 'connected' | 'connecting' | 'disconnected' | 'polling'`
  - `RealtimeEventType = 'INSERT' | 'UPDATE' | 'DELETE' | '*'`
  - `RealtimePayload<T>` with `eventType`, `new`, `old`, `table`, and `timestamp`.
  - `SubscriptionOptions` including optional filter strings, fallback polling intervals, and deduplication keys.

### Task 3: Centralized RealtimeManager
- Create `src/lib/realtime/realtime-manager.ts`:
  - Reference-counted multiplexer for Supabase channels to avoid duplicate connections per table.
  - Manages channel lifecycle: `SUBSCRIBED`, `TIMED_OUT`, `CLOSED`, `CHANNEL_ERROR`.
  - Handles reconnection with exponential backoff and jitter.
  - Provides subscriber registration and event broadcast methods.

### Task 4: Base React Hooks
- Create `src/hooks/use-realtime-connection.ts`:
  - Exposes global connection status (`connected`, `connecting`, `disconnected`, `polling`).
  - Listens to browser `online` and `offline` events to trigger immediate reconnect or disconnect transitions.
- Create `src/hooks/use-realtime-subscription.ts`:
  - Subscribes to `postgres_changes` on a specified table.
  - Automatically activates background polling (default 12s interval) when connection status is not `'connected'`.
  - Automatically terminates polling interval when WebSocket re-establishes `'connected'`.
  - Deduplicates incoming events using record ID and `updated_at` timestamps.

### Task 5: Unit Tests
- Create `tests/unit/realtime/realtime-manager.test.ts`:
  - Test channel multiplexing, reference counting on unsubscribe, and event fan-out.
- Create `tests/unit/hooks/use-realtime-subscription.test.ts`:
  - Test subscription initialization, state transitions to polling on disconnect, deduplication, and cleanup.

## Verification
- Run `cmd /c npx vitest run tests/unit/realtime/realtime-manager.test.ts tests/unit/hooks/use-realtime-subscription.test.ts`.
- Ensure all tests pass with 0 errors.
