# Plan 34.2: Web Dashboard Recommendations Card, 1-Click Remediation UI & Telegram Command

## Objective
Provide an interactive visual recommendation interface on the main Web Dashboard (`src/app/page.tsx`) with 1-click remediation buttons (`REQ-OPS-05`), and integrate a proactive advisory digest command (`/advisory`) into the Telegram bot (`REQ-OPS-04`).

## Task Breakdown

### Task 1: Web UI Recommendations Card & Dashboard Integration
- Create `src/components/advisory/recommendations-card.tsx`:
  - Visual summary header: Total active recommendations with severity pills (`Critical`, `Warning`, `Info`).
  - Recommendation cards list:
    - Severity badge, category icon, title, description, and diagnostic rationale.
    - 1-Click Remediation Action button (`Button variant="primary"` or `variant="outline"`):
      - Triggers `POST /api/advisory/remediate` with action type and payload.
      - Shows loading spinner while executing.
      - Displays success or failure notification banner upon completion.
    - Dismiss recommendation button to hide acknowledged items locally.
    - Empty state when system is fully nominal: "All Systems Nominal — Zero Maintenance Warnings".
- Update `src/app/page.tsx`:
  - Mount `RecommendationsCard` directly into the Command Center Dashboard below `SystemHealthCard`.

### Task 2: Telegram Bot `/advisory` Remote Command
- Update `src/lib/telegram/commands.ts`:
  - Add `/advisory` command handler in `handleTelegramCommand`:
    - Calls `ProactiveAdvisoryEngine.generateAdvisoryReport()`.
    - Formats output in MarkdownV2:
      - 📢 Header with total count and critical/warning badges.
      - Formatted list of top recommendations with severity icons:
        - 🔴 Critical: immediate action needed
        - 🟡 Warning: attention advised
        - 🔵 Info: proactive suggestion
      - Displays recommended remediation action name for each item.
    - If zero recommendations: outputs "✅ All Systems Nominal — No active maintenance recommendations".
  - Update `/start` command menu with:
    - `• /advisory — Proactive maintenance recommendations & health advisory`.

### Task 3: Component & Command Tests
- Create `tests/unit/components/recommendations-card.test.tsx`:
  - Test rendering of recommendation list with severity badges.
  - Test clicking 1-click remediation button triggering API execution and updating state.
  - Test nominal empty state when no recommendations exist.
  - Test error alert when remediation fails.
- Create `tests/unit/telegram/advisory-command.test.ts`:
  - Test `/start` includes `/advisory`.
  - Test `/advisory` formatting recommendations in MarkdownV2.
  - Test `/advisory` nominal output when 0 recommendations exist.
