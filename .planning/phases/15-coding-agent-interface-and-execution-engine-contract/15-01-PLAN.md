# Plan 15.1: Coding Agent Contract Types, Engine Registry & Mock Engine

## Objective
Define the provider-agnostic TypeScript contract (`ICodingAgentEngine`), Zod runtime schemas (`CodingTaskContext`, `CodingTaskResult`, `ExecutionArtifact`), centralized engine registry (`CodingEngineRegistry`), and deterministic mock engine (`MockCodingAgentEngine`) to decouple Jarvis orchestration from concrete coding CLI tools (`REQ-EX-01`, `NFR-SEC-01`).

<task type="auto">
  <name>Author Coding Agent Contract Types & Zod Schemas</name>
  <files>
    src/lib/agents/engine/types.ts
  </files>
  <action>
    Create `src/lib/agents/engine/types.ts`:
    1. Import `z` from `zod`.
    2. Define `ArtifactTypeSchema` enum: `["test_log", "build_log", "diff", "patch", "screenshot"]` and `ArtifactType`.
    3. Define `ExecutionArtifactSchema`:
       - `name`: string (min 1)
       - `artifactType`: `ArtifactTypeSchema`
       - `content`: string | Buffer (using `z.union([z.string(), z.instanceof(Buffer)])` or custom check)
       - `mimeType`: string (min 1)
       - `path`: string optional
    4. Define `TestSummarySchema`:
       - `passed`: non-negative integer
       - `failed`: non-negative integer
       - `skipped`: non-negative integer default 0
       - `durationMs`: non-negative number
    5. Define `TaskExecutionStatusSchema` enum: `["success", "test_failure", "timeout", "error"]` and `TaskExecutionStatus`.
    6. Define `CodingTaskResultSchema`:
       - `runId`: string (UUID)
       - `status`: `TaskExecutionStatusSchema`
       - `exitCode`: integer
       - `commitHash`: optional string (hex 7-40 chars)
       - `diffPatch`: optional string
       - `testSummary`: `TestSummarySchema`
       - `artifacts`: array of `ExecutionArtifactSchema`
       - `errorDetails`: optional string
    7. Define `CodingTaskContextSchema`:
       - `taskId`: string (UUID)
       - `runId`: string (UUID)
       - `stepId`: optional string
       - `projectSlug`: string (min 1)
       - `repositoryUrl`: string (min 1)
       - `targetBranch`: `z.literal("main")` — strictly enforced (`NFR-SEC-01`)
       - `scopedInstructions`: string (min 10)
       - `allowedFilePatterns`: array of non-empty strings (min 1)
       - `maxRetries`: positive integer default 3
       - `environmentVariables`: optional record of string -> string
       - `metadata`: optional record of string -> unknown
    8. Define `EngineValidationResult` interface:
       - `valid`: boolean
       - `engineName`: string
       - `version`?: string
       - `details`?: string
       - `missingRequirements`?: string[]
    9. Define `ICodingAgentEngine` interface:
       - `readonly engineName: string`
       - `executeTask(context: CodingTaskContext): Promise<CodingTaskResult>`
       - `validateEnvironment(): Promise<EngineValidationResult>`
    10. Define error classes:
       - `CodingEngineError`: base error
       - `EngineNotFoundError`: thrown when looking up an unregistered engine
       - `BranchSecurityViolationError`: thrown when target branch is not "main"
       - `EngineExecutionError`: thrown during engine execution failure
  </action>
  <verify>
    Run `pnpm exec tsc --noEmit` to verify type signatures and schema inference.
  </verify>
  <done>
    All Zod schemas, TypeScript types, ICodingAgentEngine interface, and error classes are defined and exportable without type errors.
  </done>
</task>

<task type="auto">
  <name>Implement CodingEngineRegistry & MockCodingAgentEngine</name>
  <files>
    src/lib/agents/engine/registry.ts
    src/lib/agents/engine/mock-engine.ts
  </files>
  <action>
    1. Implement `src/lib/agents/engine/registry.ts`:
       - Class `CodingEngineRegistry` with private map of engines and default engine identifier.
       - `registerEngine(engine: ICodingAgentEngine, isDefault = false): void`
       - `getEngine(name?: string): ICodingAgentEngine`: returns named engine or default engine. Throws `EngineNotFoundError` if not registered or no engines exist.
       - `hasEngine(name: string): boolean`
       - `listEngines(): string[]`
       - `setDefaultEngine(name: string): void`
       - `getDefaultEngineName(): string | undefined`
       - `unregisterEngine(name: string): boolean`
       - `validateAll(): Promise<Record<string, EngineValidationResult>>`
       - `clear(): void` (resets state for testing)
       - Export a shared singleton instance `codingEngineRegistry = new CodingEngineRegistry()`.
    2. Implement `src/lib/agents/engine/mock-engine.ts`:
       - Class `MockCodingAgentEngine implements ICodingAgentEngine`:
         - `readonly engineName: string = "mock"`
         - Constructor accepts configurable options:
           - `defaultStatus`: `"success" | "test_failure" | "timeout" | "error"` (default `"success"`)
           - `exitCode`: number (default 0)
           - `commitHash`: string (default `"a1b2c3d4e5f60718293a4b5c6d7e8f9012345678"`)
           - `diffPatch`: string (default sample unified diff)
           - `testSummary`: TestSummary (default `{ passed: 10, failed: 0, skipped: 0, durationMs: 1250 }`)
           - `artifacts`: ExecutionArtifact[] (default test log and build log)
           - `shouldThrow`: boolean
           - `validationResult`: EngineValidationResult (default valid)
           - `delayMs`: number (simulates async execution latency)
         - `executeTask(context: CodingTaskContext): Promise<CodingTaskResult>`:
           - Validates context against `CodingTaskContextSchema`.
           - Records received context in `executedContexts: CodingTaskContext[]` for inspection.
           - Returns simulated `CodingTaskResult`.
         - `validateEnvironment(): Promise<EngineValidationResult>`: returns configured validation result.
  </action>
  <verify>
    Run `pnpm exec tsc --noEmit` to verify type correctness of registry and mock engine.
  </verify>
  <done>
    CodingEngineRegistry provides full CRUD and validation for engines, and MockCodingAgentEngine provides a configurable test double.
  </done>
</task>
