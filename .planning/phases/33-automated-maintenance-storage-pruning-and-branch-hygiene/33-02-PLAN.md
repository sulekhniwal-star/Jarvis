# Plan 33.2: Continuous Branch Safety Audit, Settings Maintenance Card & Telegram Command

## Objective
Establish continuous git branch safety auditing and cleanup (`NFR-SEC-04`), provide an interactive maintenance and branch compliance card in `/settings`, and add the Telegram `/prune` slash command (`REQ-OPS-03`).

## Task Breakdown

### Task 1: Continuous Branch Safety Enforcement Engine (`NFR-SEC-04`)
- Create `src/lib/git/branch-hygiene.ts`:
  - Define `BranchHygieneReport`:
    - `isCompliant: boolean`
    - `activeBranch: string`
    - `extraneousBranches: string[]`
    - `violations: string[]`
    - `timestamp: string`
  - Implement `auditBranchHygiene(cwd)`:
    - Queries all local branches with `git branch --format="%(refname:short)"`.
    - If any branch other than `main` exists, marks `isCompliant = false` and registers violations.
    - Inspects active branch to ensure it is strictly `main`.
  - Implement `cleanExtraneousBranches(cwd, options)`:
    - Deletes non-main local branches via `git branch -D <branch>` to restore pristine hygiene.
- Update `scripts/git-guard.ts`:
  - Add `check-branch-hygiene` subcommand.
  - Integrate branch hygiene validation into the default `pre-commit` workflow.

### Task 2: Web UI Maintenance Control Card & Settings Integration
- Create `src/components/ops/maintenance-control-card.tsx`:
  - Displays last maintenance run timestamp, estimated disk space reclaimed, expired approvals count, and branch safety compliance badge (`Branch Hygiene: Main-Only Locked`).
  - Interactive "Run Pruning Maintenance" button with progress indicator.
  - "Audit Branch Safety" button with real-time compliance results.
- Update `src/app/settings/page.tsx`:
  - Mount `MaintenanceControlCard` into the settings view below cost controls.

### Task 3: Telegram Bot `/prune` Command
- Update `src/lib/telegram/commands.ts`:
  - Add `/prune` command handler in `handleTelegramCommand`.
  - Calls `StoragePruningService.runFullMaintenance()`.
  - Formats output in MarkdownV2:
    - Reclaimed bytes (MB)
    - Ephemeral build logs / artifacts pruned
    - Stale pending approvals expired
    - Branch safety verification status
  - Update `/start` command menu with `• /prune — Storage retention pruning & approval expiry`.

### Task 4: Unit, Component & Command Tests
- Create `tests/unit/git/branch-hygiene.test.ts`:
  - Test compliant status when only `main` branch exists.
  - Test violation detection when extraneous feature branches exist.
  - Test branch cleanup logic.
- Create `tests/unit/components/maintenance-control-card.test.tsx`:
  - Test rendering of maintenance metrics and branch compliance badge.
  - Test prune button click triggering maintenance API call.
- Create `tests/unit/telegram/prune-command.test.ts`:
  - Test `/start` includes `/prune`.
  - Test `/prune` execution output in MarkdownV2.
