<task type="auto">
  <name>Author Row-Level Security migration and unit test suite</name>
  <files>
    supabase/migrations/20261115000002_rls_policies.sql
    tests/unit/database/schema.test.ts
    tests/unit/database/rls.test.ts
  </files>
  <action>
    1. Author `supabase/migrations/20261115000002_rls_policies.sql`:
       - Enable RLS (`ALTER TABLE ... ENABLE ROW LEVEL SECURITY`) on all tables:
         `user_profiles`, `projects`, `milestones`, `tasks`, `specifications`, `plans`, `approvals`, `agent_runs`, `run_artifacts`, `cost_records`, `audit_events`, `memories`.
       - Create owner policies for `user_profiles` (`id = auth.uid()`).
       - Create owner policies for `projects`, `cost_records`, `approvals`, `memories` (`user_id = auth.uid()`).
       - Create join/relation policies for `milestones`, `tasks`, `specifications`, `plans`, `agent_runs`, `run_artifacts` checking parent project owner (`EXISTS (SELECT 1 FROM projects WHERE projects.id = ... AND projects.user_id = auth.uid())`).
       - Create append-only policy for `audit_events`: permit `INSERT` where `user_id = auth.uid()`, strictly deny `UPDATE` and `DELETE`.
       - Create append-only policy for `approvals`: allow `UPDATE` only on `status` and `decided_at` when `user_id = auth.uid()`, deny `DELETE`.
    2. Author `tests/unit/database/schema.test.ts`:
       - Verify file existence of both migrations and `config.toml`.
       - Parse `20261115000001_initial_schema.sql` and assert all 12 table creation statements exist.
       - Assert vector extension and HNSW index are present.
       - Assert foreign key relationships and cascade constraints.
    3. Author `tests/unit/database/rls.test.ts`:
       - Parse `20261115000002_rls_policies.sql` and assert `ENABLE ROW LEVEL SECURITY` exists for all 12 tables.
       - Assert that `auth.uid()` checks exist on all policy declarations.
       - Assert that audit events cannot be modified or deleted.

    AVOID: Allowing any table to bypass RLS.
    USE: Explicit policy names describing tenant boundaries.
  </action>

    pnpm test tests/unit/database/schema.test.ts tests/unit/database/rls.test.ts
  </verify>

  </done>
