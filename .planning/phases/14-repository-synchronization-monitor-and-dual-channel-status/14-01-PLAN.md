  <action>
    1. Update `src/lib/github/types.ts`:
       - Define `GitSyncState`: `"synced" | "ahead" | "behind" | "diverged" | "unknown"`
       - Define `GitSyncStatus`:
         ```typescript
         export interface GitSyncStatus {
           branch: string;
           isMainLocked: boolean;
           localCommitSha: string;
           localShortSha: string;
           localCommitMessage: string;
           localCommitDate: string;
           remoteRef: string;
           remoteCommitSha: string;
           remoteShortSha: string;
           aheadCount: number;
           behindCount: number;
           status: GitSyncState;
           isClean: boolean;
           uncommittedCount: number;
           lastCheckedAt: string;
         }
         ```
       - Define `SyncMonitorOptions`: `{ cwd?: string; remoteRef?: string; gitExec?: (args: string[]) => string }`
    2. Author `src/lib/github/sync-monitor.ts`:
       - Implement class `RepoSyncMonitor`:
         - Optional `gitExec` injector defaulting to child_process `execFileSync`.
         - Method `getSyncStatus(options?: SyncMonitorOptions): Promise<GitSyncStatus>` (or sync):
           - Inquire active branch (`git branch --show-current`); verify `isMainLocked = branch === "main"`.
           - Inquire working tree cleanliness (`git status --porcelain`); compute `isClean` and count uncommitted files.
           - Inquire local HEAD commit (`git log -1 --format=%H%x09%h%x09%s%x09%aI`).
           - Inquire remote ref commit (`git rev-parse <remoteRef>` or `git log -1 <remoteRef> --format=%H%x09%h`).
           - Compute ahead count (`git rev-list --count <remoteRef>..HEAD`).
           - Compute behind count (`git rev-list --count HEAD..<remoteRef>`).
           - Determine `status`:
             - `ahead > 0 && behind > 0`: `"diverged"`
             - `ahead > 0 && behind === 0`: `"ahead"`
             - `ahead === 0 && behind > 0`: `"behind"`
             - `ahead === 0 && behind === 0`: `"synced"`
           - In-memory cache with 30s TTL to prevent duplicate execution during rapid poll loops.
           - Method `clearCache()` to force refresh.
    3. Export `RepoSyncMonitor` and types from `src/lib/github/index.ts`.
  </action>
</task>
