    Create `src/lib/agents/engine/aider/repair-handler.ts`:
    1. Define repair state interfaces:
       - `RepairStrike`: `{ strikeNumber: 1 | 2 | 3; errorDetails: string; diffSnapshot?: string; instructions: string }`
       - `RepairState`: `{ currentStrike: number; maxStrikes: number; isTerminated: boolean; history: RepairStrike[] }`
    2. Implement `AiderRepairHandler` class:
       - `createInitialState(maxStrikes = 3): RepairState`
       - `recordStrike(state: RepairState, errorDetails: string, diffSnapshot?: string): { nextState: RepairState; repairPrompt: string; shouldRollback: boolean }`:
         - Strike 1: Formulates prompt targeting specific error messages and stack traces.
         - Strike 2: Formulates prompt reviewing previous diff, fixing collateral side-effects and missing dependencies.
         - Strike 3: Flags `shouldRollback = true` and `isTerminated = true`, aborting further automated attempts.
       - `compileRepairPrompt(strikeNumber: number, errorDetails: string, diffSnapshot?: string): string`
  </action>

<task type="auto">
  <name>Implement AiderCliAdapter implementing ICodingAgentEngine</name>
  <files>
    src/lib/agents/engine/aider/aider-adapter.ts
    src/lib/agents/engine/index.ts
  </files>
  <action>
    1. Create `src/lib/agents/engine/aider/aider-adapter.ts`:
       - Class `AiderCliAdapter implements ICodingAgentEngine`:
         - `readonly engineName: string = "aider"`
         - Constructor accepts options:
           - `defaultModel`: string (default `"openrouter/qwen/qwen-2.5-coder-32b-instruct"`)
           - `openRouterApiKey`?: string
           - `openRouterBaseUrl`?: string (default `"https://openrouter.ai/api/v1"`)
           - `processRunner`?: `(command: string, args: string[], options?: ProcessOptions) => Promise<AiderProcessResult>` (DI for testing)
           - `verificationRunner`?: `(command: string) => Promise<{ exitCode: number; output: string }>` (DI for tests)
           - `gitRollbackRunner`?: `(files: string[]) => Promise<void>` (DI for rollback)
         - `validateEnvironment(): Promise<EngineValidationResult>`:
           - Checks if `aider --version` responds or is executable. Returns `EngineValidationResult`.
         - `executeTask(context: CodingTaskContext): Promise<CodingTaskResult>`:
           - Validates context (`targetBranch === "main"`).
           - Synthesizes Aider CLI arguments using `synthesizeAiderArgs`.
           - Executes initial batch pass.
           - Parses output using `parseAiderOutput`.
           - If verification command is provided in context metadata:
             - Runs verification command.
             - If verification fails: executes 3-strike repair loop via `AiderRepairHandler`.
             - If strike 3 fails: executes rollback and returns `status: "test_failure"`.
           - Returns completed `CodingTaskResult`.
    2. Update `src/lib/agents/engine/index.ts`:
       - Export everything from `./aider/types`.
       - Export `AiderConfigSynthesizer`, `synthesizeAiderArgs`, `generateAiderYamlConfig` from `./aider/config-synthesizer`.
       - Export `AiderOutputParser`, `parseAiderOutput`, `extractExecutionArtifacts` from `./aider/output-parser`.
       - Export `AiderRepairHandler` from `./aider/repair-handler`.
       - Export `AiderCliAdapter` from `./aider/aider-adapter`.
       - Auto-register `AiderCliAdapter` in `codingEngineRegistry`.
  </action>
  <verify>
    Run `pnpm.cmd exec tsc --noEmit` to verify type completeness and exports.
  </verify>
  <done>
    AiderCliAdapter is implemented, exportable, and registered in the engine registry.
  </done>
</task>
