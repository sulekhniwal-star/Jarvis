# Plan 28.1: CostRepository, Spend Aggregation, Failsafe Circuit Breaker & Cost APIs

## Objective
Implement `CostRepository` data access for metered cost records in INR, the server-side failsafe `InferenceCircuitBreaker` enforcing daily (₹25) and monthly (₹750) budget caps with emergency reserve authorization (up to ₹1,000), integrate with `AIGateway`, and expose REST API endpoints.

## Task Breakdown

### Task 1: CostRepository & Spend Calculations (`REQ-COST-01`)
- Create `src/lib/repositories/cost-repository.ts`:
  - Inherits from `BaseRepository`.
  - Methods:
    - `recordUsage(userId: string, data: CreateCostRecordDTO): Promise<CostRecord>`
    - `listCostRecords(userId: string, filters?: CostFilterOptions): Promise<PaginatedResult<CostRecord>>`
    - `getDailySpendInr(userId: string, date?: Date): Promise<number>`
    - `getMonthlySpendInr(userId: string, date?: Date): Promise<number>`
    - `getSpendSummary(userId: string): Promise<CostSpendSummary>`: computes today spend, month spend, limits, emergency reserve status, circuit breaker status (`nominal` | `tripped_daily` | `tripped_monthly` | `emergency_unlocked` | `hard_locked`), recent records, and model breakdown.
    - `unlockEmergencyReserve(userId: string, reason?: string): Promise<void>`: persists emergency reserve activation in `user_profiles.preferences` for the current calendar month.

### Task 2: Failsafe Inference Circuit Breaker (`REQ-COST-02`, `NFR-REL-02`)
- Create `src/lib/ai/circuit-breaker.ts`:
  - `InferenceCircuitBreaker`:
    - Checks whether model is free: if free, immediately returns `{ allowed: true, isFree: true }`.
    - If paid model:
      - **Failsafe Rule (`NFR-REL-02`):** Wraps cost and budget verification in a try-catch. If database or service is unavailable, throws `FailsafeCircuitBreakerError` (`FAILSAFE_BLOCKED`) rather than proceeding unmetered.
      - Daily cap check: If `currentDaily + estimatedCost > dailyLimit` (₹25.00), throws `DailyBudgetExceededError`.
      - Monthly cap check: If `currentMonthly + estimatedCost > monthlyLimit` (₹750.00):
        - If emergency reserve active and `currentMonthly + estimatedCost <= absoluteCeiling` (₹1,000.00), allows request with warning.
        - If emergency reserve not active, throws `MonthlyBudgetExceededError`.
        - If `> 1000.00`, throws `HardCeilingExceededError`.
      - 80% daily warning: Emits warning message when projected daily spend exceeds ₹20.00.
- Update `src/lib/ai/gateway.ts`:
  - Integrate `InferenceCircuitBreaker` into `AIGateway` pre-inference checks.

### Task 3: REST API Endpoints
- Create `src/app/api/costs/route.ts`:
  - `GET`: Lists paginated cost records with model, date range, and run filters.
  - `POST`: Records an inference usage record (Zod validated).
- Create `src/app/api/costs/summary/route.ts`:
  - `GET`: Returns the real-time `CostSpendSummary` (daily, monthly, limits, circuit breaker state, model distribution).
- Create `src/app/api/costs/emergency-reserve/route.ts`:
  - `POST`: Activates emergency reserve for the user for the current month.

### Task 4: Unit & Integration Tests
- Create `tests/unit/repositories/cost-repository.test.ts`: Test insertion, daily/monthly calculation, filtering, and summary generation.
- Create `tests/unit/ai/circuit-breaker.test.ts`: Test free model bypass, daily cap tripping, monthly cap tripping, emergency reserve unlock, hard ceiling enforcement, and failsafe database outage behavior.
- Create `tests/unit/api/costs-routes.test.ts`: Test `GET/POST /api/costs`, `GET /api/costs/summary`, and `POST /api/costs/emergency-reserve`.
