<task type="auto">
  <name>Build Execution Stepper Timeline & Telemetry Viewer Components</name>
  <files>
    src/components/agents/run-header.tsx
    src/components/agents/execution-step-timeline.tsx
    src/components/agents/diff-viewer.tsx

    src/components/agents/run-artifacts-list.tsx
    src/components/agents/run-telemetry-view.tsx
  </files>
  <action>
    1. Create `src/components/agents/run-header.tsx`:
       - Breadcrumb navigation (`Dashboard > Agents > Run #[shortId]`).
       - Header displaying run status badge, agent engine, duration, commit hash, and task title link.
    2. Create `src/components/agents/execution-step-timeline.tsx`:
       - Stepper illustrating 4 lifecycle stages:
         - 1. Queued & Environment Scoped
         - 2. Coding Agent Execution
         - 3. Verification & Self-Review Gate
         - 4. Final Disposition (Completed / Failed / Rolled Back)
       - Color-coded state indicators (completed: green check, running: cyan pulse, failed: danger alert).
    3. Create `src/components/agents/diff-viewer.tsx`:
       - Render unified git diff patch with line-by-line syntax coloring:
         - `+` lines: green background
         - `-` lines: red background
         - `@@` hunks: cyan background
       - File modification badges and quality score indicator.
    4. Create `src/components/agents/log-viewer.tsx`:
       - Terminal container displaying stdout, stderr, or failure diagnostic messages with copy and search buttons.
    5. Create `src/components/agents/run-artifacts-list.tsx`:
       - Displays attached run artifacts with file size, mime type, and SHA-256 checksums.
    6. Create `src/components/agents/run-telemetry-view.tsx`:
       - Orchestrator unifying `RunHeader`, `ExecutionStepTimeline`, and tabbed viewer (`Diff`, `Logs`, `Test Results`, `Artifacts`).
  </action>
  <verify>
    Create unit tests in `tests/unit/components/run-telemetry.test.tsx` verifying timeline status mapping, diff line coloring, and tab switching.
  </verify>
</task>
