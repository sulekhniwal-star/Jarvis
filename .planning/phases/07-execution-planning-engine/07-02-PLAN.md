    1. Update `src/lib/repositories/types.ts`:
       - Export `Plan`, `PlanInsert`, `PlanUpdate`, `PlanStatus`, `CreatePlanDTO`.
    2. Author `src/lib/repositories/plan-repository.ts`:
       - Inherit from `BaseRepository`.
       - Method `create(dto: CreatePlanDTO): Promise<Plan>`:
         Inserts a new plan record with default `status = "draft"` and `version = 1`.
       - Method `findByTaskId(taskId: string): Promise<Plan | null>`:
         Retrieves latest plan for a task (`order("version", { ascending: false }).limit(1)`).
       - Method `findAllVersions(taskId: string): Promise<Plan[]>`:
         Retrieves chronological plan versions.
       - Method `createRevision(taskId: string, dto: Omit<CreatePlanDTO, "taskId" | "version">): Promise<Plan>`:
         Increments version number and marks previous plan as superseded or preserves history.
       - Method `updateStatus(id: string, status: PlanStatus): Promise<Plan>`:
         Updates plan status (`draft`, `pending_approval`, `approved`, `rejected`, `superseded`).
  </action>
</task>

<task type="auto">
  <name>Implement Task Planning API Route Handler</name>
  <files>
    src/app/api/tasks/[id]/plan/route.ts
  </files>
  <action>
    Author `src/app/api/tasks/[id]/plan/route.ts`:
    - `POST` route handler taking `{ params: Promise<{ id: string }> }`.
    - Retrieves task by `id` and verifies status is `specifying`.
    - Retrieves latest specification from `SpecificationRepository`. If no spec found, returns 404.
    - Dispatches `PlannerAgent.plan({ taskId, specification, projectContext })`.
    - Persists generated plan in `PlanRepository`.
    - Transitions task status from `specifying` to `planned` via `TaskRepository.updateStatus(taskId, "planned")`.
    - Returns 201 with `{ taskId, planId, status: "planned", plan: ... }`.
    - Handles errors with descriptive codes (400, 404, 409, 422, 500).
  </action>
</task>
