  <name>Author conversation schema migration and update database TypeScript types</name>
  <files>
    supabase/migrations/20261115000003_conversations.sql
    src/types/database.ts
  </files>
  <action>
    1. Author `supabase/migrations/20261115000003_conversations.sql`:
       - Create `conversations` table:
         - `id UUID PRIMARY KEY DEFAULT gen_random_uuid()`
         - `user_id UUID NOT NULL REFERENCES public.user_profiles(id) ON DELETE CASCADE`
         - `project_id UUID REFERENCES public.projects(id) ON DELETE SET NULL`
         - `title TEXT NOT NULL`
         - `channel TEXT DEFAULT 'web' NOT NULL CHECK (channel IN ('web', 'telegram'))`
         - `status TEXT DEFAULT 'active' NOT NULL CHECK (status IN ('active', 'archived'))`
         - `metadata JSONB DEFAULT '{}'::jsonb NOT NULL`
         - `created_at TIMESTAMPTZ DEFAULT NOW() NOT NULL`
         - `updated_at TIMESTAMPTZ DEFAULT NOW() NOT NULL`
       - Create `messages` table:
         - `id UUID PRIMARY KEY DEFAULT gen_random_uuid()`
         - `conversation_id UUID NOT NULL REFERENCES public.conversations(id) ON DELETE CASCADE`
         - `sender_type TEXT NOT NULL CHECK (sender_type IN ('user', 'agent', 'system'))`
         - `content TEXT NOT NULL`
         - `payload JSONB DEFAULT '{}'::jsonb NOT NULL`
         - `token_count INT DEFAULT 0 NOT NULL`
         - `created_at TIMESTAMPTZ DEFAULT NOW() NOT NULL`
       - Add performance indexes: `idx_conversations_user_id`, `idx_conversations_project_id`, `idx_messages_conversation_id`.
       - Enable RLS on both tables.
       - Add owner policies for `conversations` (`user_id = auth.uid()`).
       - Add join policy for `messages` via `conversations.user_id = auth.uid()`.
    2. Update `src/types/database.ts`:
       - Add `conversations` and `messages` table definitions under `Database['public']['Tables']`.
       - Export convenience types: `Conversation`, `Message`, `ConversationChannel`, `ConversationStatus`, `MessageSenderType`.

    AVOID: Unrestricted message payloads. Ensure structured typing for plans, code diffs, and tool execution logs.
    USE: Standard Postgres TIMESTAMPTZ and JSONB columns.
  </action>
  <verify>
    pnpm tsc --noEmit
  </verify>
  <done>
    Conversation migration and updated database type definitions compiled with 0 TypeScript errors.
  </done>
</task>
