  <name>Implement Multi-Stage Failure Diagnostic Analyzer</name>
  <files>
    src/lib/agents/engine/verification/repair/failure-analyzer.ts
  </files>
  <action>
    1. Create `src/lib/agents/engine/verification/repair/failure-analyzer.ts`:
       - Class `FailureAnalyzer`:
         - `analyze(rawOutput: string, stageName?: string): FailureDiagnostic`.
         - Inspects raw failure text to classify into one of the 7 `FailureCategory` values.
         - Extracts affected file paths using regexes for file patterns (e.g. `src/...:line:col`, `FAIL ...`, `Type error:`).
         - Extracts error snippets (assertion diffs, compiler diagnostics, lint rules).
         - Derives a targeted `suggestedStrategy`.
         - Exposes singleton `failureAnalyzer`.
  </action>
  <verify>
    Run `pnpm.cmd exec tsc --noEmit` to verify analyzer logic.
  </verify>
  <done>
    FailureAnalyzer accurately parses multi-stage errors into structured diagnostics.
  </done>
</task>

  <action>
    1. Create `src/lib/agents/engine/verification/repair/prompt-synthesizer.ts`:
       - Class `RepairPromptSynthesizer`:
         - `synthesize(diagnostic: FailureDiagnostic, strikeNumber: number, options?: { diffSnapshot?: string; allowedFiles?: string[] }): string`.
         - Formulates strike-tiered instructions (Strike 1: Minimal fix; Strike 2: Structural/dependency check; Strike 3: Final conservative fallback).
         - Injects category-specific instructions (e.g., TS type alignment, test assertion adjustment, boundary compliance, secret remediation).
         - Injects strict policy fences (must not touch unallowed files, must not insert console.log or secrets).
         - Exposes singleton `repairPromptSynthesizer`.

       - Export types, analyzer, and synthesizer.
