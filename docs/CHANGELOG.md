## [0.1.0] — 2026-11-15

### Added
- **Milestone 0 Discovery & Architecture Baseline:**
  - Mandatory GitHub branch policy (`main`-only strict mode) verified and documented.
  - Comprehensive system architecture specification (`docs/SYSTEM_ARCHITECTURE.md`).
  - Technology stack definition (`docs/TECH_STACK.md`).
  - Relational and vector database schemas (`docs/DATABASE_SCHEMA.md`).
  - API and RPC contracts (`docs/API_SPECIFICATION.md`).
  - Multi-agent taxonomy and context management protocol (`docs/AGENT_DESIGN.md`).
  - Generic coding agent interface and Aider sandbox adapter (`docs/CODING_AGENT_INTERFACE.md`).
  - Durable workflow state machine and advisory lock specifications (`docs/WORKFLOW_ENGINE.md`).
  - STRIDE threat model and prompt injection defense strategy (`docs/SECURITY_THREAT_MODEL.md`).
  - Central permission policy matrix and approval lifecycle (`docs/PERMISSION_POLICY.md`).
  - Strict INR budget controls and OpenRouter free-model hierarchy (`docs/BUDGET_AND_COST_CONTROL.md`).
  - Long-term semantic memory and pgvector RAG specifications (`docs/MEMORY_ARCHITECTURE.md`).
  - GitHub App integration and least-privilege scoping (`docs/GITHUB_INTEGRATION.md`).
  - Telegram bot gateway and mobile approval interface (`docs/TELEGRAM_INTEGRATION.md`).
  - Hosting, preview vs. production deployment strategy (`docs/DEPLOYMENT_STRATEGY.md`).
  - Test strategy and empirical proof requirements (`docs/TEST_STRATEGY.md`).
  - Backup, disaster recovery, and high-availability procedures (`docs/BACKUP_AND_RECOVERY.md`).
  - 12-milestone project roadmap (`docs/ROADMAP.md`).
  - Architecture Decision Records ADR-001 through ADR-009 (`docs/DECISIONS.md`).
  - Research log, risk register, and current state documents.
