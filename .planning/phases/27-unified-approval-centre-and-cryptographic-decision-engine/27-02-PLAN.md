# Plan 27.2: Approvals Portal UI, Action Badges, Countdown Timers & App Router Page

## Objective
Build the master Human Approvals Portal (`/approvals`) with metrics banner, status filtering tabs, search, action-specific visual badges, real-time second-by-second countdown timers, decision confirmation modals, and Supabase Realtime synchronization.

## Task Breakdown

### Task 1: Visual Action Badge & Card Components
- Create `src/components/approvals/approval-action-badge.tsx`:
  - Distinct styling for each `ApprovalActionType`:
    - `git_remote_push`: Blue badge with `GitCommit` icon.
    - `production_deploy`: Purple badge with `Rocket` icon.
    - `paid_ai_inference`: Yellow/Amber badge with `Coins` icon.
    - `destructive_db_mutation`: Rose/Red badge with `Database` icon.
    - `external_message`: Cyan badge with `Send` icon.
- Create `src/components/approvals/approval-request-card.tsx`:
  - Renders action badge, risk tier pill, target resource (monospace), and linked task details.
  - Live second-by-second countdown timer with warning colors when `< 5m` remaining.
  - Interactive "Approve" (emerald) and "Reject" (rose) buttons when in pending state.
  - Displays decision metadata and timestamp when already decided.

### Task 2: Decision Confirmation Modal
- Create `src/components/approvals/decision-modal.tsx`:
  - Accessible modal confirmation before granting or rejecting high-risk operations.
  - Optional reason textarea field.
  - Submits to `POST /api/approvals/[id]/decision` with cryptographic token.

### Task 3: Approvals Portal View & App Router Page
- Create `src/components/approvals/approvals-portal-view.tsx`:
  - Metrics cards banner: Total Requests, Pending Approvals (with pulse badge), Approved, Rejected, Expired.
  - Search input matching target resource, action type, or task title.
  - Status tabs (`All`, `Pending`, `Approved`, `Rejected`, `Expired`) with live count badges.
  - Action type filter dropdown.
  - Responsive card grid with accessible empty states.
  - Integration with `useRealtimeApprovals` for instant state updates.
- Create `src/app/approvals/page.tsx`:
  - Next.js App Router page wrapped in `AppShell` with server-side prefetching.

### Task 4: Unit & Component Tests
- Create `tests/unit/components/approvals-portal.test.tsx`:
  - Test badge rendering across all action types.
  - Test card countdown timer and status rendering.
  - Test status tab filtering and search input.
  - Test modal opening and decision execution.

## Verification
- Run `cmd /c npx vitest run tests/unit/components/approvals-portal.test.tsx`.
- Run full Vitest suite (`cmd /c npx vitest run`).
- Run Next.js production build (`cmd /c npm run build` with `BypassSandbox: true`).
