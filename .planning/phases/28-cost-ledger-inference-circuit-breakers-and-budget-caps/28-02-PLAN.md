# Plan 28.2: Cost & Budget Management UI, Financial Metrics, Ledger Table & Settings Page

## Objective
Build the client-side Cost & Budget Management interface within the `/settings` route, featuring financial guardrails metrics cards, circuit breaker status displays, emergency reserve authorization modal, filterable cost ledger table, and live data polling.

## Task Breakdown

### Task 1: Financial Metrics & Circuit Breaker Visuals
- Create `src/components/cost/cost-metrics-banner.tsx`:
  - Cards displaying:
    - Today's Spend vs ₹25.00 limit (with progress indicator)
    - Monthly Spend vs ₹750.00 limit (with progress indicator)
    - Emergency Reserve status (₹250.00, locked or unlocked)
    - Inviolable Hard Stop (₹1,000.00)
- Create `src/components/cost/circuit-breaker-card.tsx`:
  - Displays current circuit breaker state:
    - `Nominal` (emerald shield, operating normally)
    - `Tripped Daily` (amber alert, daily limit reached)
    - `Tripped Monthly` (rose alert, monthly budget reached)
    - `Emergency Reserve Active` (purple shield, ₹250 reserve authorized)
    - `Hard Locked` (dark rose alert, ₹1,000 ceiling reached)
  - Quick action button to trigger Emergency Reserve unlock modal when monthly budget is reached.

### Task 2: Granular Cost Ledger & Reserve Modal
- Create `src/components/cost/emergency-reserve-modal.tsx`:
  - Accessible modal dialog explaining the ₹250 emergency reserve terms and confirming unlock.
  - Submits to `POST /api/costs/emergency-reserve`.
- Create `src/components/cost/cost-ledger-table.tsx`:
  - Filterable table of past inferences:
    - Columns: Timestamp, Model / Provider, Run / Task, Prompt Tokens, Completion Tokens, Total Cost (₹ INR), Status.
    - Model filter dropdown and search input.
    - Pagination controls.

### Task 3: Cost Management View & Settings Page
- Create `src/components/cost/cost-management-view.tsx`:
  - Master view component orchestrating `CostMetricsBanner`, `CircuitBreakerCard`, `CostLedgerTable`, and `EmergencyReserveModal`.
  - Polling and refresh controls.
- Create `src/app/settings/page.tsx`:
  - App Router page wrapped in `AppShell` with title "System Settings".
  - Tabbed interface with default tab "Budget & Cost Control" (and tabs for "Profile", "Governance").
  - Server-side prefetching of cost summary and recent records.

### Task 4: Unit & Component Tests
- Create `tests/unit/components/cost-settings.test.tsx`:
  - Test metrics banner rendering with spend and limits.
  - Test circuit breaker visual states (`nominal`, `tripped_daily`, `tripped_monthly`, `emergency_unlocked`).
  - Test emergency reserve modal opening and confirmation flow.
  - Test cost ledger table filtering by model and text search.

## Verification

- Run full Vitest suite (`cmd /c npx vitest run`).
