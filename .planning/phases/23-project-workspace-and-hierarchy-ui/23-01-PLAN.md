## Tasks

<task type="auto">
  <name>Create Project API Routes</name>
  <files>
    src/app/api/projects/route.ts
    src/app/api/projects/[id]/route.ts
  </files>
  <action>
    1. Create `src/app/api/projects/route.ts`:
       - `GET`: Authenticate user session, instantiate `ProjectRepository`, list projects with limit/offset, and compute aggregate milestone/task metrics.
       - `POST`: Authenticate session, validate payload with Zod (`name`, `description`, `repositoryUrl`, `defaultBranch`, `settings`), call `ProjectRepository.create()`, and return 201 with project record.
    2. Create `src/app/api/projects/[id]/route.ts`:
       - `GET`: Authenticate session, fetch project by ID (or fallback to slug if UUID check fails), fetch associated milestones via `MilestoneRepository` ordered by `sequence_order`, fetch tasks via `TaskRepository` for the project, compute completion velocity (% of tasks with status `completed`), and return full hierarchy payload.
  </action>
  <verify>
    Create and run `tests/unit/api/projects-routes.test.ts` verifying GET list, POST create, and GET detail with hierarchy.
  </verify>
</task>

  <action>
    1. Create `src/components/projects/project-header.tsx`:
       - Display project title, slug, status badge, repository link with GitHub icon, default branch badge (`main`).
       - Compute and display completion velocity meter (% tasks completed, total tasks, active tasks, blocked tasks).
       - Include breadcrumb navigation (`Dashboard > Projects > [Project Name]`).
    2. Create `src/components/projects/milestone-hierarchy-view.tsx`:
       - Render milestone cards with sequence numbers, progress bars, and expandable task lists.
       - Each task item displays title, priority badge (`low`, `medium`, `high`, `urgent`), risk level, status pill, and cost estimate.
       - Include empty state when milestone has no tasks.
    3. Create `src/components/projects/create-project-modal.tsx`:
       - Accessible dialog with form fields: project name, description, repository URL, default branch.
       - Handles validation, submission to `POST /api/projects`, loading state, and redirects or refreshes on success.
    4. Create `src/components/projects/projects-index-view.tsx`:
       - Grid/list view of all projects with search input, status filter, task summary badges, and "Create Project" trigger.
  </action>
  <verify>
    Create unit tests in `tests/unit/components/projects-workspace.test.tsx` testing rendering, progress computation, and empty state.
  </verify>
</task>
