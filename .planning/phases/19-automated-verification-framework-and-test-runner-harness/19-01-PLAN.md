  <name>Define Verification Types and Output Parsers</name>
  <files>
    src/lib/agents/engine/verification/types.ts
    src/lib/agents/engine/verification/parsers.ts
  </files>
  <action>
    1. Create `src/lib/agents/engine/verification/types.ts`:
       - `VerificationStageSchema`: `z.enum(["lint", "typecheck", "test", "build", "custom"])`.
       - `VerificationStageResultSchema`: stage, command, status ("passed" | "failed" | "skipped"), exitCode, stdout, stderr, durationMs, testMetrics (`{ passed: number, failed: number, skipped: number }`), errorSummary.
       - `VerificationHarnessConfigSchema`: stages array, failFast (boolean, default true), customCommand, timeoutMs (default 30000), cwd, env, defaultCommands override map.
       - `VerificationResultSchema`: status ("passed" | "failed" | "error"), overallDurationMs, stages, summary (`TestSummary`), artifacts (`ExecutionArtifact[]`), failureStage, failureDetails.
    2. Create `src/lib/agents/engine/verification/parsers.ts`:
       - `sanitizeVerificationOutput(content: string)`: Replaces passwords, tokens, API keys, and connection strings with `[REDACTED_SECRET]`.
       - `parseVitestOutput(stdout: string, stderr: string)`: Extracts passed, failed, and skipped test counts.
       - `parseTypeScriptOutput(output: string)`: Extracts file, line, TS error code, and error count.
       - `parseESLintOutput(output: string)`: Extracts error and warning counts.
       - `parseNextBuildOutput(output: string)`: Detects route compilation, webpack errors, and type check status.
  </action>
  <verify>
    Run `pnpm.cmd exec tsc --noEmit` to verify type and parser validity.
  </verify>
  <done>
    Types and parsers compile cleanly with zero TypeScript errors.
  </done>
</task>

<task type="auto">
  <name>Implement Universal VerificationHarness</name>
  <files>
    src/lib/agents/engine/verification/verification-harness.ts
  </files>
  <action>
    1. Create `src/lib/agents/engine/verification/verification-harness.ts`:
       - Define `StageProcessRunner` injectable type.
       - Provide cross-platform default process runner using `child_process.spawn` or `execFile` with timeout protection.
       - Implement `VerificationHarness` class:
         - Constructor accepting optional `VerificationHarnessConfig` and `StageProcessRunner`.
         - `runStage(stage: VerificationStage, customCommand?: string)`: Executes a single stage with timing, output sanitization, and stage-specific parsing.
         - `runAll(overrideConfig?: Partial<VerificationHarnessConfig>)`: Iterates through configured stages in order (`lint` -> `typecheck` -> `test` -> `build` -> `custom`).
         - Honors `failFast: true` (halts remaining stages on first failure).
         - Synthesizes consolidated `TestSummary` and generates `ExecutionArtifact` objects (`test_log`, `build_log`).
         - Exposes singleton `verificationHarness`.
  </action>
  <verify>
    Run `pnpm.cmd exec tsc --noEmit` to ensure harness types and exports are clean.
  </verify>
  <done>
    VerificationHarness is fully implemented with injectable process runner and artifact generator.
  </done>
</task>
