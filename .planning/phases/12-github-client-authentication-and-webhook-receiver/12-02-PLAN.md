  <action>
    1. Author `src/lib/github/webhook.ts`:
       - `verifyGitHubWebhookSignature(rawBody: string, signatureHeader: string | null | undefined, secret: string): boolean`:
         - Extracts hex signature from `sha256=<hex>`.
         - Calculates expected HMAC SHA-256 digest using `crypto.createHmac`.
         - Verifies length match and uses `crypto.timingSafeEqual` for constant-time comparison.
       - Types:
         - `GitHubPushEvent`: `{ ref: string; before: string; after: string; repository: { name: string; full_name: string }; pusher: { name: string; email: string }; commits: Array<{ id: string; message: string; timestamp: string; author: { name: string; email: string } }> }`
         - `GitHubWorkflowRunEvent`: `{ action: string; workflow_run: { id: number; name: string; head_branch: string; head_sha: string; status: string; conclusion: string | null; html_url: string } }`
         - `GitHubPingEvent`: `{ zen: string; hook_id: number }`
    2. Export in `src/lib/github/index.ts`.
    3. Author `tests/unit/github/webhook.test.ts`:
       - Test valid signature passes.
       - Test invalid secret fails.
       - Test altered body fails.
       - Test missing or malformed header fails.
  </action>
</task>

<task type="auto">
  <name>Author GitHub Webhook App Router Route Handler</name>
  <files>
    src/app/api/github/webhook/route.ts
    tests/unit/api/github-webhook-route.test.ts
  </files>
  <action>
    1. Author `src/app/api/github/webhook/route.ts`:
       - `POST(request: NextRequest)`:
         - Reads raw request body text.
         - Reads headers: `x-hub-signature-256`, `x-github-event`, `x-github-delivery`.
         - Validates signature using `verifyGitHubWebhookSignature(bodyText, signatureHeader, process.env.GITHUB_WEBHOOK_SECRET)`. If invalid, returns 401 Unauthorized.
         - Parses body JSON.
         - Handles event types:
           - `"ping"`: returns 200 `{ ok: true, pong: true }`.
           - `"push"`:
             - If `payload.ref !== "refs/heads/main"`, logs warning: `Non-main push detected: ${payload.ref}` and returns 200 `{ ok: true, warning: "Non-main push ignored" }`.
             - If `payload.ref === "refs/heads/main"`, logs audit event and returns 200 `{ ok: true, event: "push", commitsCount: payload.commits?.length ?? 0 }`.
           - `"workflow_run"`:
             - Captures workflow conclusion, head SHA, and returns 200 `{ ok: true, event: "workflow_run", conclusion: payload.workflow_run.conclusion }`.
           - Default: returns 200 `{ ok: true, ignored: true, event: eventType }`.
    2. Author `tests/unit/api/github-webhook-route.test.ts`:
       - Test 401 on invalid signature.
       - Test 400 on malformed JSON.
       - Test 200 on ping event.
       - Test 200 on main push event with commit summary.
       - Test 200 on non-main push with warning indicator.
       - Test 200 on workflow_run event.
  </action>
</task>
