## Tasks

<task type="auto">
  <name>Build Memories API Routes (GET, POST, DELETE)</name>
  <files>
    src/app/api/memories/route.ts
    src/app/api/memories/[id]/route.ts
  </files>
  <action>
    1. Create `src/app/api/memories/route.ts`:
       - `GET`: Authenticate session, extract query params (`category`, `projectId`, `search`, `q` for semantic search, `limit`, `offset`).
       - If `q` is provided, call `MemoryRepository.searchSimilarMemories()`.
       - Otherwise call `MemoryRepository.listMemories()`.
       - Compute category metrics: `total`, `userPreferences`, `projectDecisions`, `architecturePatterns`, `historicalErrors`.
       - Return `{ memories, total, metrics }`.
       - `POST`: Authenticate session, validate payload with Zod (`category` enum, `content` min 5 chars, `projectId` optional UUID, `metadata` optional record).
       - Create memory via `MemoryRepository.createMemory()`. Return 201.
    2. Create `src/app/api/memories/[id]/route.ts`:
       - `DELETE`: Authenticate session, call `MemoryRepository.deleteMemory(id, userId)`. Return 200 `{ success: true }`.
  </action>
  <verify>
    Create unit tests in `tests/unit/api/memories-routes.test.ts` verifying filtering, semantic search endpoint, validation, and deletion.
  </verify>
</task>
